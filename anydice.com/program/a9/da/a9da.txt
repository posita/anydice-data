function: reroll A:n if below three with B:d {
 if A < 3 { result: B }
 result: A
}
MOD: 3
CHA: 3

X: [reroll d6 if below three with d6]
Y: [reroll d6 if below three with d6]
Z: X + Y + MOD + d6
output Z named "GWF"

Q: d6 + MOD + d6
R: d6 + MOD + d6
S: Q + R
output S named "TWF and DW Mastery"

BLAST: 1d10 + CHA + 1d6
output BLAST named "Blast"

DUEL: 1d8 + MOD + 1d6 + 2

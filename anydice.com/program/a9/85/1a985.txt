function: reroll lowest of ROLL:s as REROLL:d if less than MIN:n {
  LOWEST: (#ROLL)@ROLL       \ the lowest die is sorted last \
  if LOWEST >= MIN {
    result: ROLL + 0
  } else {
    REST: {1..#ROLL-1}@ROLL  \ all but the lowest die \
    result: REST + REROLL
  }
}

output d100
output [highest 1 of 2d100]
output [reroll lowest of d100 as d100 if less than 50]
output [reroll lowest of d100 as d100 if less than 30]

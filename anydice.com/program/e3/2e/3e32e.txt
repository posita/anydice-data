
function: H:n L:n vs T:n {
  R: 0

  if (L > T) & (H > T) { 
   result: -1
  }

  if (L <= T) & (H > T) {
    result: T - L
  }

  if (L <= T) & (H <= T) { 
    result: T - [ lowest of H and L ]
  }

  result: T
}



DICE: 2d20
H: 1@DICE
L: 2@DICE

  loop T over {1..20} {
    output [ H L vs T ] named "[T]"
  }

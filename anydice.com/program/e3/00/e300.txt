function: brawl A:s vs B:s {
  SA: A >= 1@B
  SB: B >= 1@A
  if SA = SB { result: (A > B) - (A < B) }
  else { result: SA - SB }
}
function: brawl A:s vs B:s with swap {
  AX: [sort { 1@B, {1..(#A-1)}@A }]
  BX: [sort { {2..#B}@B, (#A)@A }]
  NOSWAP: [brawl A vs B]
  SWAP: [brawl AX vs BX]
  result: [highest of NOSWAP and SWAP]
}
output [brawl 3d6 vs 3d6 with swap] named "A vs B Damage"

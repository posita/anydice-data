function: flail F:s G:s H:s N:s

{
if F = G = H { result: F + G + H}
if F < G < H { result: H + G - N}
if F = G < H { result: F + G }
if H < G < F { result: F + G - N}
if H < G = F { result: F + G }
if F < H < G { result: G + H - N}
if F < H = G { result: G + H }
if H < F < G { result: G + F - N}
if G < F < H { result: H + F - N}
if G < H < F { result: F + H - N}
result: 0
} 
output [flail 1d6 1d6 1d6 1d6]  named "unlucky flail"

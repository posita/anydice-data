\Ability score + any bonuses of attacker\
ATKMOD: 7

\Ability score + any bonuses of defender\
DEFMOD: 5

function: MOD:n minus ROLL:s minimum zero {
 \loop through the result and replace negative values with 0\
 NEW: {}
 loop N over {MOD - ROLL} {
  if N < 0 {
   NEW: {NEW, 0}
  }
  else {
   NEW: {NEW, N}
  }
 }
 result: NEW
}

output [ATKMOD minus 1d10 minimum zero] - [DEFMOD minus 1d10 minimum zero]

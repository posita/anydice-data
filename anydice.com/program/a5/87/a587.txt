function: ROLL:n gwf REROLL:d reroll SEQUENCE:s{
  if [SEQUENCE contains ROLL] {
    result: REROLL
  }
  else {
    result: ROLL
  }
}

ABILITY: 4
DIE_ONE: [d6 gwf d6 reroll {1,2}]
DIE_TWO: [d6 gwf d6 reroll {1,2}]
DIE_THREE: [d10 gwf d10 reroll {1,2}]

output 2 * (DIE_ONE+DIE_TWO+ABILITY) named "Greatsword with Fighting Style"
output 2 * (2d6+ABILITY) named "Greatsword"
output 2 * (1d10+ABILITY) named "Heavy Crossbow with Crossbow Expert"
output 1 * (4d6+ABILITY) named "Thunder Cannon"
output 1 * (2d8) named "Ray of Frost"

function: iscritw ROLL:n {
  if ROLL >= 24 { result: HIT }
  result: CRIT
}
function: iscrits ROLL:n {
  if ROLL >= 13 { result: HIT }
  result: CRIT
}

ROLLRESULT: 7d10
CRIT: 2
HIT: 1

BASEW: 9d10 
MULTW: 4 + 23/100
BASES: 8d10 
MULTS: 4 + 8/100

output (BASEW * MULTW) * [iscritw 1d100] named "Winter"
output (BASES * MULTS) * [iscrits 1d100] named "Summer"

function: net attack hits {
\first roll is ATTACK POOL, second roll is DEFENSE POOL\
result: [count {5, 6} in TOHIT] - [count {5, 6} in TODODGE]
}

\Computes modified weapon damage from a roll\
\modifier for the first conditional is WEAPON DAMAGE\
function: NETHITS:s modified damage value{
  if NETHITS > 0 {result: NETHITS + WEAPONDV}
  if NETHITS = 0 {result: NETHITS}
  if NETHITS < 0 {result: -1}
}


\first variable is target's AV, second is weapon AP \
function: MODDAMAGE:s compare damage to armor{

  if MODDAMAGE < 0 {result: -1}
  if MODDAMAGE = 0 {result: 0}
  if MODDAMAGE > 0 & MODDAMAGE < DEFENDERAV {result: 1}
  if MODDAMAGE > 0 & MODDAMAGE >= DEFENDERAV  {result: 2}

}

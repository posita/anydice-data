

\offhand attack\
function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: 2d6 + 5 } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: 1d6 + 5 }
 result: 0
}

\opportunity attack\
function: attackrolll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: 8d6 + 2d8 + 5 } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: 4d6 + 1d8 + 5 }
 result: 0
}

ENEMYAC: 14
BOOMINGBLADE: 2d8
FIRSTATTACK: 8d6 + 2d8 + 5


ATTACKMOD: 5
PROFICIENCY: 3
CRITROLL: 20
DAMAGE: 1d6 + ATTACKMOD 
CRITDAMAGE: 2d6 + ATTACKMOD 
output [attackroll d20 vs ENEMYAC] + [attackrolll d20 vs ENEMYAC] + FIRSTATTACK + BOOMINGBLADE named "entire round"

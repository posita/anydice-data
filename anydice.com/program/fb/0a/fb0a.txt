\Armor Values\
ARMLVL: 0
ARMTIER: 1
EVA: 2d{ARMLVL..((ARMTIER-1)*(2+ARMLVL))}/2
REG: 2d{ARMLVL..(ARMTIER*(2+ARMLVL))}/2
DEF: 2d{ARMLVL..((ARMTIER+1)*(2+ARMLVL))}/2

\Damage Values\
DMG: 2d{1..4}/2

\Function to treat negative damage as 0\
function: A:n above zero {
  if A > 0 { result: A }
  result: 0
}

\Actual output commands\
output [DMG - EVA above zero] named "evasion"
output [DMG - REG above zero] named "default"
output [DMG - DEF above zero] named "defence"

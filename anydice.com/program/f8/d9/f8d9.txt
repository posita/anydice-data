\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + ATTACKMOD >= AC { result: DAMAGE }
 result: 0
}

ATTACKMOD: 4
CRITROLL: 20
DAMAGE: 1d6 + 2
CRITDAMAGE: 2d6 + 2
ATTACKTIMES: 13d2



output ATTACKTIMESd[attackroll [lowest 1 of 2d20] vs 15] named "Javelin +2"


function: A:n and B:n {
 if A < 3 { result: B}

function: ROLL:n vs AC:n {
 if ROLL = 1 { result: MISS }
 if ROLL = 20{ result: CRITICALHIT }
 if ROLL + ATTACK >= AC { result: HIT }
 result: MISS
}


AC: 18
STRENGTH: 4
MAGICITEM: 1
PROFICIENCY: 3
ATTACK: PROFICIENCY + MAGICITEM + STRENGTH
MISS: 0
HIT: [1d10 and 1d10] + 1d6 + MAGICITEM + STRENGTH
CRITICALHIT: HIT + [1d10 and 1d10] + [1d10 and 1d10]
output [d20 vs AC] named "Brightspear"

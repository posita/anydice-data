\H is the number dice rolled to hit (e.g 2 - basic)(a negative number will mean lower 2 dice)\
\W is the injury table threshold you want to see on injury table (incl. armor) (e.g 9 - kill)\
\I is the number of dice rolled to injure (e.g. - 2 basic)(a negative number will mean lower 2 dice out of pool abs(I))\


function: roll A:n{
if A>0{result: {1,2}@Ad6}
if A<0{
A:[absolute A]
result: {A-1,A}@Ad6
}}


function: chance H:s W:n I:n {
if H>0{
   I: I+1
   if [roll I]>=W {result: 1}
   else{result: 0}
   }
}



output [roll ]

\H is the number of dice used to roll when hitting (0 is an automatic hit)\
\I is the number of dice used to damaage\
\W is the number expected when rolling injury\
\(when using negative numbers of dice please subtract 2 from the number (e.g. when a unit has -2R, write -4))\

function: roll A:n Z:n{
Z:Z+2
if A>0{result: [highest Z of Ad6]}
if A<0{
A:[absolute A]
result: [lowest 2 of Ad6]
}}

function: trafienie H:n{
R: [roll H 0]
result: R>=7
}


function: damage W:n I:n A:n{
result: [roll I A]>=W
}

function: final hit H:n injure I:n threshold W:n additive A:n{
if H=0{result: [damage W I A]}
result: [trafienie H]*[damage W I A]
}

output [final hit 0 injure -3 threshold 7 additive 0]

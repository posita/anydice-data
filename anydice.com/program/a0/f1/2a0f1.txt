function: roll A:n ac B:n {
 if A >= B { result: 1 }
 result: 0
}

AC: 12 \armor class\
AM: 4 \ability modifier\
PB: 2 \proficiency bonus\
DD: d12 \damage die\
HIT: [roll d20 ac AC-AM-PB]
OUTONE: (DD+AM+2)*HIT

output OUTONE

DWD: d4 \dual wield die\
OUTTWO: (DWD+AM)*HIT + (DWD+AM)*HIT

output OUTTWO

function: roll A:n ac B:n {
 if A >= B { result: 1 }
 result: 0
}

AC: 14 \armor class\
AM: 3 \ability modifier\
PB: 2 \proficiency bonus\
DD: d12 \damage die\
HITONE: [roll d20 ac AC-AM-PB+5]
OUTONE: (DD+AM+10)*HITONE

output OUTONE

DWD: d8 \dual wield die\
HITTWO: [roll d20 ac AC-AM-PB]
HITTHREE: [roll d20 ac AC-AM-PB]
OUTTWO: (DWD+AM)*HITTWO + (DWD)*HITTHREE

output OUTTWO

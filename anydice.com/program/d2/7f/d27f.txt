\ Enemy Armor Class \
AC:13

\ Accuracy Function \
function: acc A:n B:n C:n D:n E:n F:n{
if A=1 {result: 0}
else if A>1 & A<C & A+B < AC {result: 0}
else if A>1 & A<C & A+B > AC {result: D+E+F}
else if A>=C {result: D*2+E+F}
}

\ Re-rolling dice below a certain number \
function: rronedeefour R:n under N:n {
   if R < N { result: 1d4 } else {result: R}
}
function: rronedeesix R:n under N:n {
   if R < N { result: 1d6 } else {result: R}
}
function: rronedeeeight R:n under N:n {
   if R < N { result: 1d8 } else {result: R}
}
function: rronedeeten R:n under N:n {
   if R < N { result: 1d10 } else {result: R}
}
function: rronedeetwelve R:n under N:n {
   if R < N { result: 1d12 } else {result: R}
}

\ Lucky feat \
function: lucky R:n N:n{
   if R < N { result: N } else {result: R}
}

\ Output \
\ [Function Name] [attack die] [attack bonus] [minimum crit] [damage dice] [damage bonus] [extra modifiers(Superiority dice)] \
output [acc [lucky 1d20 1d20] 7 20 1d6 5 2d6] named "Hand Crossbow with Sneak Attack and Lucky Example"

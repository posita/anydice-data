function: X:n if at most Y:n else Z:n {
  if X <= Y { result: X }
  else { result: Z }
}

X: [NdF if at most N-K else 0]  \ number of fails on N rolls (or 0 if more than N-K) \

output XdL / 4 named "(sum of [N]d12 less than [L]) / 4 with at least [K] successes"

\
1d20 approximation of Apocalypse World dice
Result 2 (15 or higher) is a strong hit
Result 1 (7-14) is a weak hit
Result 0 (6 or lower) is a miss

Total to-hit bonus range is 0 to +6
Total difficulty/AC bonus range is 0 to -5
\

function: pbta ROLL:n {  
if ROLL >= 15 {result: 2}
if ROLL <= 7 {result: 0}
result: 1
}

loop MODIFIERS over {-5..6} {  
output [pbta 1d20 + MODIFIERS] named "[MODIFIERS]"  
}

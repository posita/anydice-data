\ Probabilidad de pago para trabajar \
function: work A:n {
 if A <= 9 { result: 1 }
 if A <= 14 { result: 5 }
 if A <= 20 { result: 10 }
 if A >= 21 { result: 35 }
 result: A
}
\            dado  mod prof extra                           \
output [work 1d20 + 4 + 3  + 3   ] named "Pago por trabajar"

\ output [ATTACKS vs AC crit THREAT MULT CRITEXTRA dmg DAMAGE EXTRA dr DR] named "My Weapon"
This function calculates how much damage you do on an attack
ATTACKS is your attack bonus (e.g. 10), this can include iterative attacks (e.g. {6,1})
AC is the opponent's armor class (e.g. 17)
THREAT is the lower number of the critical threat range (e.g. 19 if your threat is 19-20)
MULT is your critical multiplier (e.g. 2)
CRITEXTRA is extra damage dice only on a critical hit (e.g. 1d10 for a flaming burst sword) otherwise leave blank
DAMAGE is the damage you deal with your weapon not including extra dice (e.g. 1d8+2)
EXTRA is extra damage dice (e.g. 1d6 for a sneak attack) otherwise leave blank 
DR is damage resistance \

function: ATTACKS:s vs AC:n crit THREAT:n MULT:n CRITEXTRA:d dmg DAMAGE:d EXTRA:d dr DR:n{
  SUM: {0}
  loop ATTACK over ATTACKS {
    SUM: SUM + [1d20 conf 1d20 plus ATTACK ac AC crit THREAT MULT CRITEXTRA dmg DAMAGE EXTRA dr DR]
  }
  result: SUM
}
function: ATTACKS:s vs AC:n crit THREAT:n MULT:n dmg DAMAGE:d dr DR:n{
  result: [ATTACKS vs AC crit THREAT MULT 0 dmg DAMAGE 0 dr DR]
}
function: ATTACKS:s vs AC:n crit THREAT:n MULT:n CRITEXTRA:d dmg DAMAGE:d dr DR:n{
  result: [ATTACKS vs AC crit THR
EAT MULT CRITEXTRA dmg DAMAGE 0 dr DR]
}
function: ATTACKS:s vs AC:n crit THREAT:n MULT:n dmg DAMAGE:d EXTRA:d dr DR:n{
  result: [ATTACKS vs AC crit THREAT MULT 0 dmg DAMAGE EXTRA dr DR]
}
function: ROLL:n conf CONFIRM:n plus ATTACK:n ac AC:n crit THREAT:n MULT:n CRITEXTRA:d dmg DAMAGE:d EXTRA:d dr DR:n {
  if ((ROLL = 20) & (CONFIRM + ATTACK >= AC)) { result: [highest of ([crit MULT DAMAGE] + EXTRA + CRITEXTRA - DR) and 0] } 
  if (ROLL = 20) { result: [highest of ((DAMAGE + EXTRA) - DR) and 0] }
  if (ROLL = 1) { result: 0 }
  if ((ROLL >= THREAT) & (CONFIRM + ATTACK >= AC)) { result: [highest of ([crit MULT DAMAGE] + EXTRA + CRITEXTRA - DR) and 0] }
  result: [highest of ((ROLL + ATTACK >= AC) * (DAMAGE + EXTRA - DR)) and 0]
}
function: crit MULT:n DAMAGE:d {
  SUM: {0}
  loop N over {1..MULT} {
    SUM: SUM + DAMAGE
  }
  result: SUM
}

\
Spiel—Price—Void
————————————————
\

function: spiel SPIEL:n price PRICE:n void VOID:n
{ if SPIEL>PRICE & SPIEL>VOID  { result: 1 } \ success \
  if PRICE>VOID                { result: 2 } \ success with price \
                                 result: 3 } \ void \

\ NB: Where result = 3, PRICE<=VOID (from result 2) & SPIEL<=VOID (else result would be 1) \

output [spiel 1d6 price 1d6 void 1d6] named "all sixes"
output [spiel 0d6 price 1d6 void 1d6] named "no spiel"
output [spiel 1d6 price 0d6 void 1d6] named "no price"
output [spiel 1d6 price 1d6 void 0d6] named "no void"
\output [spiel 0d6 price 0d6 void 1d6] named "no spiel / no price"\           \always void [3]\
\output [spiel 0d6 price 1d6 void 0d6] named "no spiel / no void"\            \always price [2]\
\output [spiel 1d6 price 0d6 void 0d6] named "no price / no void"\            \always spiel [1]\
\output [spiel 0d6 price 0d6 void 0d6] named "no spiel / no price / no void"\ \always void [3]\

output [spiel 4@4d6 price 0d6 void 3]

\
 Game Design Erfolgswahrscheinlichkeiten
 0: Things go bad.
 1: Success, but with undesired consequences.
 2: Clean success.
 3: Critical success!
\

function: blades ROLL:s {
 if 1@ROLL = 7 {
  result: 2 + (2@ROLL = 7)
 }
 result: 1@ROLL >= 4
}

loop P over {1..7} {
 output [blades Pd7] named "[P]d"
}

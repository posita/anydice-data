\Project Orion Roll Calculator\

function: roll with M:n accdif {
   if M > 0 { result: {1,2}@(2+M)d6 }
   else if M < 0 { result: {(2-M)-1,(2-M)}@(2-M)d6 }
   else if M = 0 { result: 2d6 }
}

output [roll with 3 accdif]

output [roll with -2 accdif]



\ Alternate version with bonus included
function: roll with M:n accdif plus B:n {
   if M > 0 { result: {1,2}@(2+M)d6 + B }
   else if M < 0 { result: {(2-M)-1,(2-M)}@(2-M)d6 + B }
   else if M = 0 { result: 2d6 + B }
}

output [roll with 3 accdif plus 0]

output [roll with -2 accdif plus 0]

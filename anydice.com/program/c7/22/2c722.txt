\Project Orion Attack Probability Calculator
Usage Instructions:
Value of AD is accuracy/difficulty affecting attack (Positive values are Accuracy, Negative values are Difficulty)
Value of FM represents any flat modifiers to to hit (Lock, Jam, base stats, etc.)
\

AD: 0
FM: 0

function: roll with M:n accdif {
   if M > 0 { result: {1,2}@(2+M)d6 }
   else if M < 0 { result: {(2-M)-1,(2-M)}@(2-M)d6 }
   else if M = 0 { result: 2d6 }
}

function: iscrit D:n {
    if D = 12 { result: 1 }
    else {result:0}
}

output [iscrit [roll with AD accdif]] named "Crit Chance"

function: attack D:n plus MOD:n vs EVA:n  {
    if D = 12 { result: 1 }
    else if D + MOD >= EVA { result: 1 } 
    else {result:0}
}

loop EVA over {2..12} {
    output [attack [roll with AD accdif] plus FM vs EVA] named "To Hit Against Evasion [EVA]"
}

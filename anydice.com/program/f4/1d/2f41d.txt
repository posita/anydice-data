set "explode depth" to 3
POKEBALL: d{2,1,1,1,0,0}
BALL: d{10,2,1,1,1,0}			

\
Notes to self:
If exploding result is added into new total, BALL should reduce the "2" successes. (10,2,1,1,1,0)
If exploded value counts as a "zero", then use BALL (10,2,2,1,1,0)
Findings, including exploded result is negligible. Increasing value to "2" causes a dramatic increase in success. Too much.
\

output 4dPOKEBALL named "pokeball"
output 5dPOKEBALL named "greatball"
output 6dPOKEBALL named "ultraball"


function: explode ROLLEDVALUE:n {
 if ROLLEDVALUE = 10 { result: 1 + [explode dBALL] }
 result: ROLLEDVALUE
}

EXPLODED: [explode dBALL]

output 4d EXPLODED named "Exploding Pokeball"
output 5d EXPLODED named "Exploding Greatball"
output 6d EXPLODED named "Exploding Ultraball"

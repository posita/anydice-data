function: at least V:n from D:s {
 X: 0
 loop N over {1..#(D)} {
  if N@D > V { X: X + 1 }
 }
 result: X
}

function: attack ATK:d vs ARM:n {
 result: [at least ARM from ATK]
}

function: defend DEF:d vs ACC:n {
 result: [at least ACC from DEF]
}

function: engage ATK:d attack vs ARM:n armor and DEF:d defense vs ACC:n accuracy {
 result: [attack ATK vs ARM] - [defend DEF vs ACC]
}

output [engage 7d6 attack vs 3 armor and 4d6 defense vs 2 accuracy]

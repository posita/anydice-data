function: at least V:n from D:s {
 X: 0
 loop N over {1..#(D)} {
  if N@D >= V { X: X + 1 }
 }
 result: X
}

function: attack ATK:d vs ARM:n {
 result: [at least ARM from ATK]
}

function: defend DEF:d vs ACC:n {
 result: [at least ACC from ATK]
}

function: engage ATK:d attack vs ARM:n armor and DEF:d defense vs ACC:n accuracy {
 result: [attack ATK vs ARM] - [defend DEF vs ACC]
}

output [engage 4d6  attack vs 4  armor and 1d6  defense vs 5  accuracy]
output [engage 4d12 attack vs 8  armor and 1d12 defense vs 10 accuracy]
output [engage 4d20 attack vs 14 armor and 1d20 defense vs 17 accuracy]

function: reroll A:n D:n if below B:n {
C:0
 \if the first die is less than 3, roll it again and add it to the result\  
 if A < B {C: C + 1d6}
 \if the first die is greater than or equal to 3, add the first dice to the result\
 else if A >= B {C: C + 1@A}
      
 if D < B {C: C + 1d6}
 else if D >= B {C: C + 2@A}
result: C
}
output [reroll 1d6 1d6 if below 3]

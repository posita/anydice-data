\My best attempt at a Forbidden Lands setup.                                         \
\To use it, in place of 3d6, or 1d12, you would use one of the representations below.\
\d6  - {0:5,1}                                                                       \
\d8  - {0:5,1,1,2}                                                                   \
\d10 - {0:5,1,1,2,2,3}                                                               \
\d12 - {0:5,1,1,2,2,3,3,4}                                                           \
\the 0:5 simply represents the 5 dice faces that don't contribute any successes      \
\For example, 4d6 + 1d12 would be written as:                                        \
\4d{0:5,1} + 1d{0:5,1,1,2,2,3,3,4}                                                   \
\------------------------------------------------------------------------------------\

output 1d{0:5,1} + 1d{0:5,1,1,2} + 1d{0:5,1,1,2,2,3} + 1d{0:5,1,1,2,2,3,3,4} named "1d6+1d8+1d10+1d12"

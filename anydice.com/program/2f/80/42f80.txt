\function used to calculate the odds of damage dealt against vehicles\

function: hit A:n AC AP:n BS D {
 if A<=BS {
  result: 0
 } else {
  if AP<=AC {
   result: 0
  } else {
   result: D
  }
 }
}

AC: 13       \Armour of the side being hit\
RS: 1d6+10+1 \Ranged Strength, +1 for armourbane\
BS: 2        \The value needed to hit, didn't want to use a lookup table for ballistic skill\
D: 6         \Damage per unsaved wound\
AN: 2        \Number of attacks\

T:0          \Variable used to calculate the total\

loop N over {1..AN} {
 T: T + [hit 1d6 AC RS BS D]
}

output T

\ not really using surgeblocks here but the calc is the same \
function: ATTACK:n vs DEFENSE:n with surgeblock SB:n{
  if ATTACK - (DEFENSE + SB) < 0 {result: 0}
  result: ATTACK - (DEFENSE + SB)
}

ATKROLL: BG

output ATKROLL named "base attack roll"
output [ATKROLL vs BLACKDIE with surgeblock 0] named "attack vs black"

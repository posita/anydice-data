function: filterlessthanzero X:n
{
    if X < 0 {result: 0}
    result: X
}

ATTACKERDICE: 5
ARMOURDICE: 5
COVERVALUE: 2
DISTANCEMOVED: 2

output [filterlessthanzero (ATTACKERDICE d(d6=1) - ARMOURDICE d(d6=1))] named "[ATTACKERDICE] attacker dice vs [ARMOURDICE] armour dice"

output [filterlessthanzero ((ATTACKERDICE-DISTANCEMOVED) d(d6=1) - ARMOURDICE d(d6=1))] named "[ATTACKERDICE] - [DISTANCEMOVED] attacker dice vs [ARMOURDICE] armour dice (running)"

output [filterlessthanzero (ATTACKERDICE d(d6=1) - (ARMOURDICE+COVERVALUE) d(d6=1))] named "[ATTACKERDICE] attacker dice vs [ARMOURDICE] + [COVERVALUE] armour dice (cover)"

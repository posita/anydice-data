\damage per round (dpr)\

function: damage if HIT:n plus MOD:n hits ac AC:n with DMG_DIE:n die plus D_MOD:n and level S:n smite on crit C{
  if HIT=20 {
    if S {
      result: 2*DMG_DIE+D_MOD+(1+S)d8*2
    }
    else {
      result: 2*DMG_DIE+D_MOD
    }
  }
  else if HIT = 1 {
    result: 0
  }
  else if HIT+MOD>=AC {
    if S & !C {
      result: DMG_DIE+D_MOD+(1+S)d8
    }
    else {
      result: DMG_DIE+D_MOD
    }
  }
  else {
    result:0
  }
}

HIT_MOD: 6+d4
DMG_MOD: 4
DMG:     d10+d4

\Level 2: 1 attack per round\
output [damage if 1d20 plus HIT_MOD hits ac 12 with DMG die plus DMG_MOD and level 1 smite on crit 0] named "Level 2 - smite on every hit"
output [damage if 1d20 plus HIT_MOD hits ac 12 with DMG die plus DMG_MOD and level 1 smite on crit 1] named "Level 2 - smite only on crit"

HIT_MOD: 7+d4
DMG_MOD: 4

output 2d[damage if 1d20 plus HIT_MOD hits ac 12 with DMG die plus DMG_MOD and level 2 smite on crit 1] + 1d[damage if 1d20 plus HIT_MOD hits ac 12 with d4+d4 die plus DMG_MOD and level 2 smite on crit 0]named "Level 5 - smite only on crit"

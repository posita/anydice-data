\ Setting up dice structures \
BLUEDIE: d{0,0,0,0,1,1}
GREENDIE: d{0,0,0,1,1,1}
YELLOWDIE: d{0,0,1,1,1,2}
REDDIE: d{0,0,0,0,0,1}
BLACKDIE: d{0,0,0,0,0,1}
WHITEDIE: d{0,0,1,1,1,99}

\ setting up dice combination variables -- use one of these in the ATKROLL variable below \
BBY: BLUEDIE + BLUEDIE + YELLOWDIE
BYY: BLUEDIE + YELLOWDIE + YELLOWDIE
BGY: BLUEDIE + YELLOWDIE + GREENDIE
BRY: BLUEDIE + REDDIE + YELLOWDIE
BRG: BLUEDIE + REDDIE + YELLOWDIE
RGY: REDDIE + GREENDIE + YELLOWDIE
BG: BLUEDIE + GREENDIE
BR: BLUEDIE + REDDIE
BY: BLUEDIE + YELLOWDIE
RY: REDDIE + YELLOWDIE
BB: BLUEDIE + BLUEDIE
GG: GREENDIE + GREENDIE
RG: REDDIE + GREENDIE
GY: GREENDIE + YELLOWDIE
RR: REDDIE + REDDIE

\ the function that computes attack results \
function: ATTACK:n vs DEFENSE:n with surgeblock SB:n{
  if DEFENSE + SB < 0 {result: ATTACK}
  if ATTACK - (DEFENSE + SB) < 0 {result: 0}
  result: ATTACK - (DEFENSE + SB)
}

\ *** User input needed here *** \
\ Assign the ATKROLL variable to one of the dice combination variables above \
\ e.g. ATKROLL: BG \
ATKROLL: BG

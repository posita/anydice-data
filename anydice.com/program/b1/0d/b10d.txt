\ Setting up dice structures \
BLUEDIE: d{0,1,1,1,2,2}
GREENDIE: d{0,1,1,2,2,2}
YELLOWDIE: d{0,0,1,1,1,2}
REDDIE: d{1,2,2,2,3,3}
BLACKDIE: d{0,1,1,2,2,3}
WHITEDIE: d{0,0,1,1,1,99}

\ setting up dice combination variables -- use one of these in the ATKROLL variable below \
BBY: BLUEDIE + BLUEDIE + YELLOWDIE
BYY: BLUEDIE + YELLOWDIE + YELLOWDIE
BGY: BLUEDIE + YELLOWDIE + GREENDIE
BRY: BLUEDIE + REDDIE + YELLOWDIE
BRG: BLUEDIE + REDDIE + YELLOWDIE
RGY: REDDIE + GREENDIE + YELLOWDIE
BG: BLUEDIE + GREENDIE
BR: BLUEDIE + REDDIE
BY: BLUEDIE + YELLOWDIE
RY: REDDIE + YELLOWDIE
BB: BLUEDIE + BLUEDIE
GG: GREENDIE + GREENDIE
RG: REDDIE + GREENDIE
GY: GREENDIE + YELLOWDIE
RR: REDDIE + REDDIE

\ the function that computes attack results \
function: ATTACK:n vs DEFENSE:n with block B:n{
  if DEFENSE + B < 0 {result: ATTACK}
  if ATTACK - (DEFENSE + B) < 0 {result: 0}
  result: ATTACK - (DEFENSE + B)
}

\ *** User input needed here *** \
\ Assign the ATKROLL variable to one of the dice combination variables above \
\ e.g. ATKROLL: BG \
ATKROLL: BG

\ computing results \
output ATKROLL named "base attack roll"
output [ATKROLL vs BLACKDIE with block 0] named "attack vs black"
output [ATKROLL vs WHITEDIE with block 0] named "attack vs white"
output [ATKROLL + GREENDIE vs BLACKDIE with block 0] named "attack vs black with focus"
output [ATKROLL + GREENDIE vs WHITEDIE with block 0] named "attack vs white with focus"
output [ATKROLL vs BLACKDIE with block 1] named "attack vs black with +1 block"
output [ATKROLL vs WHITEDIE with block 1] named "attack vs white with +1 block"
output [ATKROLL + GREENDIE vs BLACKDIE with block 1] named "attack vs black with +1 block and focus"
output [ATKROLL + GREENDIE vs WHITEDIE with block 1] named "attack vs white with +1 block and focus"

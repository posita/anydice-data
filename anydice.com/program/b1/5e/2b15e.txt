\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + ATTACKMOD >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..25}

ATTACKMOD: 18
DMGBONUS: 25
CRITROLL: 19
DAMAGE: 1d8  + DMGBONUS
CRITDAMAGE: 2d8  + DMGBONUS
A: [attackroll d20 vs ENEMYAC]


DAMAGE: 1d8+6d8+ ATTACKMOD + DMGBONUS
CRITDAMAGE: 2d8+12d8 + ATTACKMOD + DMGBONUS
B: [attackroll d20 vs ENEMYAC] 

output A+B

function: gamble GP stake with INS ins DEC dec and INT int {
X: 0
X: X + (1d20 + INS >= 2d10 + 5)
X: X + (1d20 + DEC >= 2d12 + 4)
X: X + (1d20 + INT >= 1d20 + 3)
result: [help X GP]
}
function: help V:n S {
if V = 0 {result: 0 - S / 2}
if V = 1 {result: 0 - S / 4}
if V = 2 {result: S + S / 2}
if V = 3 {result: S + S}
}
output [gamble 400 stake with 3 ins 7 dec and 4 int]

\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + HIT >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..20}

HIT: 11
DMGBONUS: 5
CRITROLL: 20
ATTACKTIMES: 15
DAMAGE: 1d10 + 1d6 + DMGBONUS
CRITDAMAGE: 2d10 + 2d6 + DMGBONUS
output ATTACKTIMESd[attackroll [highest 1 of 1d20] vs ENEMYAC] named "Lothar"

\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL + ACCBONUS >= AC { result: DAMAGE }
 result: MISSDAMAGE
}


ENEMYAC: d{12..19}

ACCBONUS: 13
CRITROLL: 20
ATTACKTIMES: 2
DAMAGE: 6+5+1d8+1d4+3d6+1d6+2+2+1d4+10+1d8 
CRITDAMAGE: 6+5+2d8+2d4+6d6+2d6+2+2+2d4+10+2d8
MISSDAMAGE: 3d6 / 2
output ATTACKTIMESd[attackroll 1d20 vs ENEMYAC] named "Paladin"

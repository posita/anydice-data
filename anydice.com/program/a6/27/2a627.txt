\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 10-20\
ENEMYAC: d{10..20}

ACCBONUS: 2
ATTACKMOD: 5
DMGBONUS: 7
PROFICIENCY: 4
CRITROLL: 20
ATTACKTIMES: 2
DAMAGE: 1d6 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 4d6 + ATTACKMOD + DMGBONUS
output ATTACKTIMESd[attackroll [highest 1 of 2d20] vs ENEMYAC] named "Bokan at 9 / Reckless Attack / +2 Weapon"

output 1d6+4 named "Zealot Bonus Damage"

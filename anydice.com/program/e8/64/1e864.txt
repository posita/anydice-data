\ Stats for single attacks, no advantage \

function: critmult ATTACK:n versus AC:n damage DAMAGE:d plus BONUS:d {
if ATTACK = 1 { result: 0 }
if ATTACK + DEX < AC { result: 0}
if ATTACK = 20 { result: 2dDAMAGE + BONUS }
result: DAMAGE + BONUS
}

SNEAK: 4d6
DEX: 4
TARGET_AC: 19

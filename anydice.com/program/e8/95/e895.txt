\
\How much better is advantage for damage vs. for check?\

AC: 14
X: 1d20
Y: [highest 1 of 2d20]
Z: [lowest 1 of 2d20]

\Returns 1 for a crit and 0 otherwise\
function: crit A:n {
  if A = 20 {
    result: 1
  }
  else {
    result: 0
  }
}

CRITX: [crit X]
CRITY: [crit Y]
CRITZ: [crit Z]

output X named "Check w/o advantage"
output Y named "Check w/ advantage"
output Z named "Check w/ disadvantage"
output (X +4 +2 >= AC)*(1d10 +4 +2 +1d6 +1 + CRITX * (1d10 + 1d10 +1d6)) named "Attack w/o advantage"
output (Y +4 +2 >= AC)*(1d10 +4 +2 +1d6 +1 + CRITY * (1d10 + 1d10 +1d6)) named "Attack w/ advantage"
output (Z +4 +2 >= AC)*(1d10 +4 +2 +1d6 +1 + CRITZ * (1d10 + 1d10 +1d6)) named "Attack w/ disadvantage"

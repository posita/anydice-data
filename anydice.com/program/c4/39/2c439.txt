function: reroll lowest of ROLL:s or both REROLL:s as of SINGLE:d if any result less than MIN:n {

   LOWEST: {#ROLL}@ROLL    \ lowest result from the initial roll \
   HIGHEST: {1..#ROLL}@ROLL \ highest result from the initial roll \
   LOWESTT: {#REROLL}@REROLL \ lowest result when rolling both initial results \


   if LOWEST >= MIN {       \ both initial results 4 or higher (no re-roll)\
        result: LOWEST } 

   if HIGHEST < MIN {       \ both initial results lower than 4 (two re-rolls)\
        result: LOWESTT }

   if LOWEST < MIN {        \ lower initial result lower than 4 (one re-roll)\
        result: SINGLE }
}
   
output [reroll lowest of 2d10 or both 2d10 as of 1d10 if any result less than 4]

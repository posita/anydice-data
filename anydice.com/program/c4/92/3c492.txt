Q: d{0..3}
\Goal : to count the successes of x+ with pairing :
 - count the direct successes number of the target : 2+ -> count all 2s & 3s.
 - remove these dices from the pool.
 - look at possible pair from the remaining dices : 2+ -> pairs of (1,1).\

\Explanation :
First, we separate [3s,2s] & [1s,0s].
Then we can find the 3s : [MAX value possible of the interval] - [Actual value] = 2s
                          [Size Interval] - 2s = 3s
Roll: {3,3,3,3,2,2,1,1,1,1,1,0}
Part 1 : {1,1,1,1,1,0} = 5 donc 5x1s
Part 2 : {3,3,3,3,2,2} = 16 for 6 parts       3*6=18 -> 18-16=2 -> 2(2s) & (6-2)(3s)
\

\****************************** Old Function **********************************\
function: old overflowing pairing SEQUENCE:s on TARGET:n {
 TEMP: {0,0,0}
 TOTAL: 0
 IDX: 1
 END: 0
 loop M over {1..#SEQUENCE} {
    if (M@SEQUENCE >= 2) & ((M+1)@SEQUENCE < 2) & (END=0) {
      IDX: M+1
      END: 1
 }}

 LOWPART: {IDX..#SEQUENCE}@SEQUENCE      \sequence with 1s & 0s\
 UN: {1:LOWPART}                               \UN: {1:(SEQUENCE=1)} ??? \
 DEUX: {1:((IDX-1)*3 - {1..IDX-1}@SEQUENCE)}
 TROIS: {1:((IDX-1) - DEUX)}
 TEMP: {#UN, #DEUX, #TROIS}
 TOTAL: {TARGET..3}@TEMP

 if(TARGET=6){result: TOTAL + (TROIS/2)}
 if(TARGET=5){result: TOTAL + ((TROIS+{1..#TROIS}@DEUX)/2)}
 if(TARGET=4){result: TOTAL + ((TROIS+({1..#TROIS}@{1:(UN+DEUX)}) + ({(TROIS-UN+1)..#DEUX}@DEUX))/2)}
 if(TARGET=3){result: TOTAL + ((DEUX+{1..#DEUX}@UN)/2)}
 if(TARGET=2){result: TOTAL + (UN/2)}

 result: TOTAL
}


\************************* Optimized Function **********************************\

function: overflowing pairing SEQUENCE:s on TARGET:n {

 TOTAL: 0
\count of number in sequence\
 UN:    SEQUENCE=1
 DEUX:  SEQUENCE=2
 TROIS: SEQUENCE=3
 TEMP: {UN, DEUX, TROIS}
\sum of chosen numbers'occurencies\
 TOTAL: {TARGET..3}@TEMP

\boolean checks : 0 or 1 multiplicators\
 DT: DEUX>=TROIS
 UT: UN>=TROIS
 UD: UN>=DEUX

 if(TARGET=6){result: TROIS/2}
 if(TARGET=5){result: (TROIS+ (DT*TROIS)+(!DT*DEUX)) /2}
 if(TARGET=4){result: (TROIS+ (UT*(TROIS+DEUX)) + (!UT*(UN+DEUX))) /2}
 if(TARGET=3){result: TOTAL + ( (DEUX+ (UD*DEUX)+(!UD*UN)) /2)}
 if(TARGET=2){result: TOTAL + (UN/2)}
 if(TARGET=1){result: TOTAL}
 result: TOTAL
}

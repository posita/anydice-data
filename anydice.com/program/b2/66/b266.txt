\**
This is a function to roll an attack roll and output the damage. If the attack roll misses, the output will be zero. The function takes four arguments as input:
ATTACK - the attack die (which should always be 1d100);
DC - the DC to hit the enemy;
DAMAGE - the number of sides on the damage die (the function assumes 2d# damage); and
CRIT - the value of the Grimm/Combat synergy damage bonus to majors and crits.
**\

function: ATTACK:n vs DC:n rolling two DAMAGE:n sided dice plus CRIT:n{
 THRESH: DC/10
 if ATTACK < DC { result: 0 }
 if ATTACK > 60+4*THRESH { result: 4dDAMAGE+CRIT }
 result: 2dDAMAGE
}

EVASION: 10
ATTACK: 1d20
DDN: 2
DF: 0

D: DDNd6+DF
DC: {1..DDN}@((2*DDN)d6)+DF

PMISS: EVASION > ATTACK
PHIT: (EVASION <= ATTACK) & (ATTACK < 20)
PCRIT: ATTACK >= 20

function: classify DX:d {
  if DX >= EVASION {
    if DX >= 20 {
      result: DC
    } 
    else {
      result: D
    }
  }
  else {
    result: 0
  }
}

output [classify 1d20]

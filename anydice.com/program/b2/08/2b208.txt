\Defines the Feat die\
F: {0..10, 999}

\Defines the Success die if character is weary\
W: {0, 0, 0, 4, 5, 6}

\the function expects the follwing inputs: Feat die, Success dice, Fixed modifier (number), and TN (number)\
function: onering FEAT:s SUCCESS:s MOD:n TN:n{
 TOTAL: FEAT + SUCCESS + MOD
 TENGWARS: [count 6 in SUCCESS]
 if TENGWARS >1 {LEVEL: 3}
 if TENGWARS = 1 {LEVEL: 2}
 if TENGWARS = 0 {LEVEL: 1}
 if TOTAL >= TN {result: LEVEL}
 else {result: 0}
}

output [onering 1dF 3d6 5 15] named "Forward"
output [onering 1dF 3d6 5 18] named "Open"
output [onering 1dF 3d6 5 21] named "Defensive"
output [onering 1dF 3dW 5 15] named "Forward (Weary)"
output [onering 1dF 3dW 5 18] named "Open (Weary)"
output [onering 1dF 3dW 5 21] named "Defensive (Weary)"

\
Output-Key
0 = Fail
1 = Success
2 = Great Success
3 = Extraordinary Success
\

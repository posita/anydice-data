\ --- WEG D6 Wild Die with Unlimited Explosions & Botch Tracking --- \

\ 1. Recursive function: keeps exploding as long as 6s are rolled \
function: explode DIE:n {
   if DIE = 6 { result: 6 + [explode 1d6] }
   result: DIE
}

\ 2. Check if the reroll after an initial 1 produces a Botch \
function: check botch REROLL:n {
   if REROLL = 6 { result: -1 } \ Internal flag for a Botch \
   result: 1 \ Non-botch 1 adds normally to total \
}

\ 3. Main Wild Die resolution \
function: wild DIE:n {
   if DIE = 6 { result: 6 + [explode 1d6] }
   if DIE = 1 { result: [check botch 1d6] }
   result: DIE
}

\ 4. Combine Normal Dice with Wild Die and preserve actual roll on botch \
function: parse wild W:n NORMAL:n {
   if W = -1 { result: -(NORMAL + 1) } \ Returns negative of actual roll on a botch \
   result: NORMAL + W
}

\ 5. Main Skill Roll Function \
function: weg skill DICE:n {
   result: [parse wild [wild 1d6] (DICE - 1)d6]
}

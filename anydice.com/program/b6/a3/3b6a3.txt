\Gambling, decent character, +2 Insight, +5 Deception, +5 Intimidation, a charisma based character can easily achieve this\
\==================================================================
| inputs
\
\ define the three rolls you will be performing against the DC \
ROLLA: 1d20 + 2         \ first skill or ability check\
ROLLB: 1d20 + 5         \ second skill or ability check \
ROLLC: 1d20 + 5         \ third skill or ability check \


\==================================================================
| functions
\
\ determines if a roll beats the given DC \
function: check A:n is above B:n {
 if A > B { result: 1 }
 result: 0
}

\ determines the winnings from a group of checks \
function: winnings from A:n {
 if A = 0 { result: -2 }
 if A = 1 { result: -1/2 }
 if A = 2 { result: 3/2 }
 if A = 3 { result: 2 }
 result: 0
}

\==================================================================
| simulation
\
DC: 5 + 2d10
TOT: [check ROLLA is above DC] + [check ROLLB is above DC] + [check ROLLC is above DC]
output [winnings from TOT]  named "Gambling Winnings"

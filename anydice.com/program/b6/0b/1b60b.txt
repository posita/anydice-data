\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
if ROLL >= 20 { result: CRITDAMAGE }
if ROLL = 1 { result: 0 }
if ROLL + ATTACKMOD >= AC { result: DAMAGE }
result: 0
}

ATTACKMOD: 17
ATTACKTIMES: 7
DAMAGE: 5d8 + 9
CRITDAMAGE: 10d8 + 9

output ATTACKTIMESd[attackroll [highest 1 of 2d20] vs 20] named "Ultar vs. AC 20 with advantage"

function: multiattack AC:n ABONUS:n ATTACK:d X:n {
  TOTAL: 0
  loop N over {1..X} {
    DAMAGE: ((1d20 + ABONUS) > AC) * ATTACK
    TOTAL: TOTAL + DAMAGE
  }
  result: TOTAL
}

AC: 18
BONUS: 3
output [multiattack AC BONUS (1d4+4) 10] named "Animate Object"
output [multiattack AC BONUS (2d6) 5] named "Scorching Ray"

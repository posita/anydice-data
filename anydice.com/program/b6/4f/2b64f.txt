\This program calculates successes when doing downtime things in XGE. Currently "replace skill check with tool proficiency" is not implemented\

\Example shown here is gambling with my PC, using Borrowed knowledge and enhance ability to buff 3 skills\

PB: 3 \your PB\
MOD_ONE: 4 \Mod for 1st skill check, in this case, deception, with my cha of +4 \
MOD_TWO: 4 \Mod for 2nd skill check, in this case, intimidation, with my cha of +4 \
MOD_THREE: 2 \Mod for 3rd skill check, in this case, insight, with my wis of +2 \

\Use this if the roll has advantage\
function: outcome adv MOD:n{
DC: 5+2d10
ROLL: 1@2d20+MOD+1d4
A: ROLL>=DC
result: A
}

\Use this if the roll does not have advantage\
function: outcome MOD:n {
DC: 5+2d10
ROLL: 1@1d20+MOD+1d4
A: ROLL>=DC
result: A
}

output [outcome adv PB+MOD_ONE]+[outcome adv PB+MOD_TWO]+[outcome PB+MOD_THREE] named "Number of passes"

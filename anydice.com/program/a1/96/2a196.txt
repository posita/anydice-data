\DIFFICULTY is the target number, the die is ... the die that you want to use. Itâ€™s supposed to be a D10\
\The result of 1 means a success, -1 means rolling a â€œ1â€ and losing a success, 0 means neither (a fail).\

	if DIE >= DIFFICULTY {result: 1}
	if DIE = 1 {result: -1}
	result: 0

\====The functions below are the core of this program====\


\The way different types of data work on AnyDice is heavily abused. You may read about this in the Documentation tab of AnyDice.com\

function: smartevaluate ROLL:s using AUTO autosuccess {
		\It accepts a sequence of numbers that are roll results from the function(s) above: 1s being success dice, -1s being botch dice, 0s being neither, and 2s indicating rolling a 10 for a roll within specialty.\
	if (ROLL > 0) > 0 {
			\First, in the line above, it checks if there are successes (results of >0, namely 1 or 2) in a given sequence, basically if the number of such results is greater than zero\
			
		NBROFTEN: [count 2 in ROLL]
		NBROFONE: [count -1 in ROLL]
		ROLLFIX: {ROLL, -1:[lowest of NBROFTEN and NBROFONE]}
			\In V20, a 1 cancel the highest dice. So in case of speciality, 2 success are lost when a 1 cancel a 10\
			\Here we add "fake" -1 to cancel the second success of a 10"\

		EVALUATION: [clampatzero ROLLFIX]
		result: EVALUATION + AUTO
			\If there are any, it feeds the sequence variable to a function that accepts numbers. This means summing up all of its numbers, returned as a roll result and fed to a function. As we announce the result, the function is stopped.\
			\Since there is no in-game difference between rolling a negative number of successes or zero, provided that you rolled at least one success, we clamp the number of successes rolled at zero. This is the thing that the â€œclampatzeroâ€ function does, besides actually clamping it.\
			\Positive values of this sum are different numbers of successes, 0 and negatives are Fails, but again, negatives are displayed as zero for calculation purposes.\
	}
	if (ROLL = -1) > 0 & AUTO = 0 {
			\If no successes are found, it checks for â€œ1â€s, or botch dice.\
			\Willpower and others auto-success PREVENTS critical failure (Core Book p. 273)\
		result: -1
			\If there are any, as we already know that there are no successes, it declares a Botch (results in -1)\
			\Because of the possible result of -1, this is not usable for calculating the average number of successes in any given situation\
			\I changed it from -1000 to -1 to make the graphs readable. AVERAGE IS STILL WRONG\
	}
	result: AUTO
		\If neither â€œ1â€s nor successes are rolled, it announces 0 as the only possible result. The roll result is a Fail, or an auto-success if possible (Willpower, Potence, ...)\
}

\--\

\You canâ€™t botch in some combat situations, like a damage roll. Or a botch can simply not bother you in some cases.\
\So the function above canâ€™t return less than 0, this result covers all botches and all fails.\
\Other results are different degrees of success.\
\The main usage of this function is to calculate average number of successes per roll with a given dice pool against a given difficulty.\

function: nobotchevaluate ROLL:n {
	if (ROLL < 0) {result: 0}
	result: ROLL
}



\==== Wrapper functions====\


\These functions are here to make the main code easier to read.\

\Use this to roll a normal test (with or without Willpower)\

function: roll DICEPOOL dice vs DIFICULTY with AUTO autosuccess {
	DICEROLL: [diceroll d10 vs DIFFICULTY]
	result: [smartevaluate DICEPOOL d DICEROLL using AUTO autosuccess]
}

\--\

\Use this to roll a normal test with speciality\

function: roll DICEPOOL dice vs DIFICULTY with AUTO autosuccess and speciality  {
	DICEROLL: [specialtyroll d10 vs DIFFICULTY double over 10]
	result: [smartevaluate DICEPOOL d DICEROLL using AUTO autosuccess]
}

\--\

\Use this to roll a damage test (or any other test where 1s do not remove success\

function: roll DICEPOOL dice vs DIFICULTY for damage {
	DICEROLL: [diceroll d10 vs DIFFICULTY]
	result: [nobotchevaluate DICEPOOL d DICEROLL]
}

loop DIFFICULTY over {6..6} {
	loop DICEPOOL over {1..10} {
		output [roll DICEPOOL dice vs DIFFICULTY with 0 autosuccess] named "Dicepool of [DICEPOOL] vs difficulty of [DIFFICULTY]"
	}
}

\Specify the ranges of the DICEPOOL (between 1 and ~250) and the DIFFICULTY (between 2 and 10)\
\Every dice pool within range will be rolled against every difficulty within range. \
\The loops roll a given number of dice against a given difficulty, evaluating the sequences for possible Botches, then return the result of a roll.\
\If -1 is returned, it is a Botch. Positive numbers are different degrees of success, 0 is a fail.\

\ roll some dice which may be red (R) or black (B) or some combination;
  if red dice (R) ≥ target (T), achieve success with consequence (2),
  else if black dice (B) ≥ target (T), achieve pure success (1),
  else failure (3) \

function: target T:n red R:n black B:n
{ if R<T & B<T  { result: 3 }
  if R>=T  { result: 2 }
  result: 1 }

\ example \
output [target 4   red 0       black 4@4d6]   named "4 black"
output [target 4   red 0       black 3@3d6]   named "3 black"
output [target 4   red 1@1d6   black 3@3d6]   named "3 black + 1 red"
output [target 4   red 0       black 2@2d6]   named "2 black"
output [target 4   red 1@1d6   black 2@2d6]   named "2 black + 1 red"
output [target 4   red 1@2d6   black 2@2d6]   named "2 black + 2 red"
output [target 4   red 0       black 1@1d6]   named "1 black"
output [target 4   red 1@1d6   black 1@1d6]   named "1 black + 1 red"
output [target 4   red 1@2d6   black 1@1d6]   named "1 black + 2 red"
output [target 4   red 1@3d6   black 1@1d6]   named "1 black + 3 red"
output [target 4   red 1@1d6   black 0]       named "1 red"

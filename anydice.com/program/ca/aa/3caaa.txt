SKIRMISH: d{0,1}
ASSAULT: d{0,1,1,1,2,2}
RAID: d{0,0,0,1,1,2}

function: reroll lowest of ROLL:s as REROLL:d if less than MIN:n {
  LOWEST: (#ROLL)@ROLL       \ the lowest die is sorted last \
  if LOWEST >= MIN {
    result: ROLL + 0
  } else {
    REST: {1..#ROLL-1}@ROLL  \ all but the lowest die \
    result: REST + REROLL
  }
}

output [reroll lowest of 2dSKIRMISH as dSKIRMISH if less than 1]
output 2dSKIRMISH
output 2dRAID

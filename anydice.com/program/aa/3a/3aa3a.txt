CRITFAIL: 0 \ Double odds   (1, 3, 5, 7, 9) \
FAIL: 1 \ Red > Black   (e.g.: B5 / R8) \
SUCCESS: 2 \ Black > Red   (e.g.: B9 / R4) \
CRITPASS: 3 \ Double evens (2, 4, 6, 8, 10) \

\ Initial idea, abandoned partway through. \
function: profittest BLACK and RED
{
 if BLACK > RED {result: SUCCESS}
 else if RED >= BLACK {result:FAIL}
}

function: redmarkets BLACK:n and RED:n
{
 \ Checking for crits first
 PROFIT: BLACK - RED
 if PROFIT > 0 {result: SUCCESS}
 else if PROFIT <= 0 {result:FAIL} \ Ties (PROFIT = 0) go to the Market \
}

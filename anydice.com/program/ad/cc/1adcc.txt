function: maximize lowest DIESIZE:n of ROLL:s {
  LOWEST: (#ROLL)@ROLL       \ the lowest die is sorted last \
  if LOWEST >= DIESIZE {
    result: ROLL + 0
  } else {
    REST: {1..#ROLL-1}@ROLL  \ all but the lowest die \
    result: REST + DIESIZE
  }
}

N:1
D:12
MOD:4

DAMAGE:NdD
PERKINS:D
CRITDAMAGE:(2*N)dD
HOUSERULE:D+(N-1)dD

output PERKINS+DAMAGE+MOD named "perkins criticals"
output [maximize lowest 12 of CRITDAMAGE]+MOD named "elite criticals"
output [maximize lowest 12 of DAMAGE]+DAMAGE+MOD named "lethal criticals"
output HOUSERULE+DAMAGE+MOD named "boosted criticals"
output DAMAGE+DAMAGE+MOD named "base criticals"

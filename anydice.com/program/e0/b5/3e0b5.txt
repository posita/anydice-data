\ Example from: Advantage by Default <https://www.prismaticwasteland.com/blog/advantage-by-default> \

X: 1d20
C: 10
D: 4

\ Results: -1 crit fail, 0 fail, 1 success at cost, 2 success, 3 crit success \
function: score X:n given D:n and C:n {
if X = C {
 result: 3
} else if X = D {
 result: -1
} else if X < D {
 result: 1
} else if X < C {
 result: 2
} else {
 result: 0
}
}

output [score X given D and C] named "no dis/advantage"
output [highest of [score 1d20 given 4 and 10] and [score 1d20 given 4 and 10]] named "advantage"
output [lowest of [score 1d20 given 4 and 10] and [score 1d20 given 4 and 10]] named "disadvantage"

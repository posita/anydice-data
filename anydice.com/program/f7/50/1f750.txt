\ Hexblade Paladin can hit some big damage spikes \
\ This looks at the damage output potentials of a build to maximize advantage from Vow of Enmity and hexblade curse \
\ Elven Accuracy means that each attack has a 15% chance of a critical hit, and Hexblade Curse (19 or 20) increases that to 27% per attack \
\ With two attacks per round, there's about a 50% chance per round of at least 1 critical hit. \

\ Damage Sources for 12-15 level character \
WEAP: 1d8   \ Typical martial one-hand weapons \
BONUS: +7   \ Hex Weapon and Dueling style for +5+2 bonus damage \
CENSER: 1d8 \ Devotee's Censer (rare) adds an extra 1d8 radiant to each strike \

CURSE: +5   \ Bonus action cast, no concentration \
MARK: 1d6   \ Bonus action cast, takes concentration \

ROLLED: WEAP+CENSER+MARK
STATIC: BONUS+CURSE

SMITE_ONE: 2d8  \ Divine Smite using level 1 spell slot, extra undead/fiend damage ignored \
SMITE_FOUR: 5d8 \ Divine smite using level 4 spell slot \

\ Normal damage output for 1 attack \
output ROLLED + STATIC named "Normal (Hunter's Mark, Hexblade Curse)"
output ROLLED + STATIC + SMITE_FOUR named "Normal (Hunter's Mark, Hexblade Curse, Smite)"

\ Critical Hit damage output for 1 attack \
output (ROLLED+ROLLED) + STATIC named "Critical Hit (Hunter's Mark, Hexblade Curse)"
output (ROLLED+ROLLED) + STATIC + (SMITE_FOUR+SMITE_FOUR) named "Critical Hit (Hunter's Mark, Hexblade Curse, Smite)"

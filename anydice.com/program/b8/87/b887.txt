\
Hit Chance Calculator:
Currently the outputs are setup to compare regular chance to get hit normally vs Haste's +2 to AC vs Blur's effect of being hit with disadvantage. Change as needed.

Output: 
0 is the critical miss chance
1 is the miss chance
2 is the hit chance
3 is the critical hit chance
\

\The settings. Change as desired.\
AC: 17+5
MOD: 10

\The attack function. Crit fail on natural one. Crit on natural twenty.\
function: ROLL:n ATTACKMOD vs AC {

if ROLL = 1 {result: 0}

\Delete backslashes on next line if 19 crits.\
\if ROLL = 19 {result: 3}\

if ROLL = 20 {result: 3}

if ROLL + ATTACKMOD >= AC {result: 2}

else { result: 1 }
}

\The output. Change as needed.\
output [ 1d20 MOD vs AC] named "Normal AC"
output [ 1d20 MOD vs AC+2] named "Haste's +2 AC"
output [ [lowest 1 of 2d20] MOD vs AC] named "Blur"
output [ 1d20 MOD vs AC+5] named "Normal AC + Shield"
output [ 1d20 MOD vs AC+2+5] named "Haste's +2 AC + Shield"
output [ [lowest 1 of 2d20] MOD vs AC+5] named "Blur + Shield"

\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..20}

ATTACKMOD: 5
DMGBONUS: 0
PROFICIENCY: 6
ACCBONUS: 0
CRITROLL: 20
DAMAGE: 1d10 + 1d6 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 2d10 + 2d6 + ATTACKMOD + DMGBONUS
output [attackroll d20 vs ENEMYAC] named "Warlock 17 Elderitch (Agonizing) blast each attack"
output 4*[attackroll d20 vs ENEMYAC] named "Warlock 17 Elderitch (Agonizing) blast All attack"

\**** Damage calculator full basic damage dealing list ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..20}

ATTACKMOD: 6
DMGBONUS: 10
PROFICIENCY: 6
ACCBONUS: 0
CRITROLL: 19
ATTACKTIMES: 3
DAMAGE: 1d8 + 2d12 + 5d8 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 2d8 + 4d12 + 10d8 + ATTACKMOD + DMGBONUS
output ATTACKTIMESd[attackroll [highest 1 of 2d20] vs ENEMYAC] named "L40 BS Tenser."

function: reroll ROLL:s with REROLLS:n rerolls below Y:n using DIE:d{
REROLLS: [lowest of #(ROLL) and REROLLS]
SUM: {1..(#(ROLL)-REROLLS)}@(ROLL)
loop N over {(#(ROLL)-REROLLS+1)..#(ROLL)}{
 if N@(ROLL)>=Y {SUM:SUM+N@(ROLL)} else {SUM:SUM+DIE}
}
result: SUM
}
output [reroll 3d10 with 3 rerolls below 6 using d10]

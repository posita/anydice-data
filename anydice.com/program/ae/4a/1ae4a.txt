function: reverse T
{
 X: {}
 loop P over {1..#T}{
  X: {P@T, X}
 }
 result: X
}

function: test A:s against S
{
D: [reverse A]
R: 0
if 1@D <= S {R: R + 1@D}
if 2@D = R {R: R + 2@D}
if 3@D = R - 2@D {R: R + 3@D}
result: R
}

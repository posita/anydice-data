function: attack ROLL:n plus BONUS:n vs AC:n for DMG:d crit CRIT_DMG:d on CRIT_RANGE:n {
    if ROLL = 1 {
        result: 0
    }
    if ROLL >= CRIT_RANGE {
        result: DMG + CRIT_DMG
    }
    if ROLL + BONUS >= AC {
        result: DMG
    }
    result: 0
}

AC: d{10..20}
BONUS: 9
output 2d[attack 1d20 plus BONUS vs AC for 1d4+6+2d6 crit 2d4+12+2d6 on 19]

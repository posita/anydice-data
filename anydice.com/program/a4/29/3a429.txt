\sequences generated by rolls are sorted in descending order so by stripping out the lower numbers we remove already checked numbers\
function: values lower than NUM:n in SEQ:s {
  RESULT: {}
  loop N over {1..#SEQ} {
    if N@SEQ < NUM { RESULT: {RESULT, N@SEQ} }
  }
  result: RESULT
}

function: count of distinct integers in SEQ:s {
  TOTAL: #SEQ
  loop N over {1..(#SEQ-1)} {
    if N@SEQ = (N+1)@SEQ { TOTAL: TOTAL - 1 }
  }
  result: TOTAL
}

\best means most matches. I'm making my life easy by assuming two doubles are worth the same as a triple and a single\
function: return best WIDTH:n in DICE:s {
  BEST_DIS: WIDTH+1
  BEST_SEQ: {0}
  \since the biggest individual die is at position 1, {1..1@DICE} gets us 1 to (the highest die in the sequence) so no checking 6 if there's no 6s in it\ 
  loop X over {1..#DICE} {
    COUNT: X@DICE = DICE
    P_SEQ: {X@DICE:WIDTH}
    DISTINCT: [count of distinct integers in P_SEQ]
    if COUNT >= WIDTH {
      if DISTINCT < BEST_DIS {
        BEST_DIS: 1
        BEST_SEQ: {X@DICE:WIDTH}
      }
    }
    else {
\    because somebody got all fancy and added arbitrary widths as an option I had to step up my game and now you've got recursion in here I hope you're happy I don't even know how to express this thing's runtime in Big O notation\
      P_SEQ: {X@DICE:COUNT}
      A: [values lower than X@DICE in DICE]
      Q: [return best (WIDTH-COUNT) in A]
      loop I over {1..#Q} {
          P_SEQ: {P_SEQ, I@Q}
      }
      DISTINCT: [count of distinct integers in P_SEQ]
      if DISTINCT < BEST_DIS {
        BEST_DIS: DISTINCT
        BEST_SEQ: P_SEQ
      }
    }
  }
  result: BEST_SEQ
}

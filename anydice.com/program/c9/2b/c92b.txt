function: owod N:n tn TN:n SP:n {
 if N = 1 { result: -1 }
 if N < TN { result: 0 }
 if N < 10 { result: 1 }
 if SP = 1{ result: 2}
 result: 1
}

OWOD: [owod d10 tn 6 0]  \If specialized, last number is 1;  otherwise 0\

loop N over {1..10} {
 output [highest of [lowest of NdOWOD and 15] and -4] named "[N]d"
}

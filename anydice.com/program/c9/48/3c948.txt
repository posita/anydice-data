\ Ironsworn dice roll. Strong Hit=2, Weak Hit=1, Miss=0 \

function: compare R:n to X:n and Y:n {
  if R > X {
  if R > Y {
   result : 2
  }
  else {
    result : 1
  }
 }
 else {
  if R > Y {
   result : 1
  }
  else {
    result : 0
  }
 }
}

\ Transposed: Shows the likelihood of a M, WH, or SH across power levels. \

output [compare 1d6+d3 to d10 and d10] named "Mundane"
output [compare 1@2d6+d3 to d10 and d10] named "Subtle"
output [compare 1@3d6+d3 to d10 and d10] named "Precise"
output [compare 1@4d6+d3 to d10 and d10] named "Potent"

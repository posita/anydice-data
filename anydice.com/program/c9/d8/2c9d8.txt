\ output [ATTACKS vs AC dmg DAMAGE precision PRECISION crit CONFIRM vs THREATRANGE mult MULT extra CRITEXTRA] named "My Weapon"
This function calculates how much damage you do on an attack
ATTACKS is your attack bonus (e.g. 10), this can include iterative attacks (e.g. {6,1})
AC is the opponent's armor class (e.g. 17)
THREATRANGE is the lower number of the critical threat range (e.g. 19 if your threat is 19-20)
MULT is your critical multiplier (e.g. 2)
CRITEXTRA is extra damage dice only on a critical hit (e.g. 1d10 for a flaming burst sword) otherwise leave blank
DAMAGE is the damage you deal with your weapon not including extra dice (e.g. 1d8+2)
PRECISION is precision damage (e.g. 1d6 for a sneak attack) otherwise leave blank \

function: ATTACKS:s vs AC:n dmg DAMAGE:d precision PRECISION:d crit CONFIRM:d vs THREATRANGE:n mult MULT:n extra CRITEXTRA:d{
  SUM: {0}
  loop ATTACK over ATTACKS {
    SUM: SUM + [1d20 plus ATTACK vs AC dmg DAMAGE precision PRECISION:d crit CONFIRM vs THREATRANGE mult MULT extra CRITEXTRA]
  }
  result: SUM
}

\ Simulation \
function: ROLL:n plus ATTACK:n ac AC:n crit THREAT:n MULT:n CRITEXTRA:d dmg DAMAGE:d EXTRA:d {
  if (ROLL = 20){
    result: (1d20 + ATTACK >= AC)*([crit MULT-1 DAMAGE] + CRITEXTRA) + DAMAGE + EXTRA }
  if (ROLL = 1) { result: 0 }
  if (ROLL + ATTACK >= AC) { 
    if (ROLL >= THREAT) {
      result: (1d20 + ATTACK >= AC)*([crit MULT-1 DAMAGE]  + CRITEXTRA) + EXTRA + DAMAGE }
    result: (DAMAGE + EXTRA)}
  result: 0
}
function: crit MULT:n DAMAGE:d {
  SUM: {0}
  loop N over {1..MULT} {
    SUM: SUM + DAMAGE
  }
  result: SUM
}
function: LEFT:n gt RIGHT:n {result: LEFT>RIGHT}

\H is D20, B is hit Bouns, A is array of AC's, D is weapon damage, S is Strength Bonus, C is Crit, M is Multiplier\

function: hit H:n B:n A:n D:d S:n C:n M:n{
 if H = 20 {result: [crit 1d20 B A D S C M]}
 if A > H+B {result: 0}
 result: [hit help H B A D S C M]
}

function: hit help H:n B:n A:n D:d S:n C:n M:n{
 if H < C {result: 1d[dam D]+S}
 result: [crit 1d20 B A D S C M]
}

function: crit H:n B:n A:n D:d S:n C:n M:n{
 if A > H+B {result: 1d[dam D]+S}
 result: Md[dam D]+M*S
}

function: dam D:n{
 result: D
}

\H is D20, B is hit Bouns, A is array of AC's, D is weapon damage, S is Strength Bonus, C is Crit, M is Multiplier\
\BAB 20, STR 28, 10 to 20 AC, +5 greatsword, power attack, fighter +5 weapon training bonus\
output [hit 1d20 35 (2d6+28) 2d6 45 17 2]

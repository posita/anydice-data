\
 Blades in the Dark-style with d10s
 -1: Bad bad bad bad.
 0: A Miss/Failure; Things go bad - that is they do not happen as you expected.
 1: Weak Hit/Mixed Success. i.e. a Success - you do what you were trying to do - but with some undesirable consequences.
 2: Good Hit/Clean success. It happens as you say.
 3: Strong Hit/Critical success! Success but things go better than you anticipated.
\

function: blades ROLL:s {
 if 1@ROLL = 10 {
  result: 2 + (2@ROLL = 10)
 }
 if 1@ROLL <3 {
  result: -1
 }
  result: 1@ROLL >= 7
}

output [blades 2@2d10] named "0d"
loop P over {1..10} {
 output [blades Pd10] named "[P]d"
}

\**** Relentless Rage ****\

function: attackroll ROLL:n vs DC:n {
 if ROLL + PROFICIENCY + MOD + BONUS >= DC { result: SUCCEED } 
 if ROLL + PROFICIENCY + MOD + BONUS < DC { result: FAILURE }
}

\looped against DC from 10 or 15\
DC: d{10}

MOD: 2
BONUS: 0
PROFICIENCY: 3
ATTACKTIMES: 1
SUCCEED: 1
FAILURE: 0
output ATTACKTIMESd[attackroll d20 vs DC] named "Relentless Rage"

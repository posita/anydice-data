\
3 Up 3 Down Method
-----------------------
First, roll a d6, a d8, and a d10. Next, fill in the Input Values below with what you rolled. Finally, hit "Calculate", and it will spit out the numbers you rolled.
\

\Input Values\

\D6 Result\
SIX: 3
\D8 Result\
EIGHT:3
\D10 Result\
TEN:3





\PROGRAM STARTS HERE\

output 10+SIX named "Attribute 1"
output 15-SIX named "Attribute 2"
output 10+EIGHT named "Attribute 3"
output 15-EIGHT named "Attribute 4"
output 8+TEN named "Attribute 5"
output 17-TEN named "Attribute 6"

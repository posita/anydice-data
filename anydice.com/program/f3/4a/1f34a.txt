DIFFICULTY: -5
\ difficulty starts at -5 which yields 100% pistol enemies. \
\ as it increments positively, more enemy types are added until all \
\ enemy types are available at difficulty 0. \
\ increment difficulty positively and it will skew toward \
\ heavy enemies the higher it gets. \
A: 3d6+DIFFICULTY

function: reroll D:n {
 if D<13 {
  result: [reroll D]
 } else {
  result: D
 }
}

output [lowest of [highest of [reroll A] and 13] and 18]-12

\**** Reggie's chances of attacking ****\

function: lattackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: LCRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: LDAMAGE }
 result: 0
}


function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}



\looped against enemy AC from 15-20\
ENEMYAC: d{18}

ATTACKMOD: 4
DMGBONUS: 1
PROFICIENCY: 3
ACCBONUS: 1
CRITROLL: 20
ATTACKTIMES: 2

LDAMAGE: 1d12 + ATTACKMOD + DMGBONUS
LCRITDAMAGE: 2d12 + ATTACKMOD + DMGBONUS

DAMAGE: 1d10 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 2d10 + ATTACKMOD + DMGBONUS

output ATTACKTIMESd[attackroll 1d20 vs ENEMYAC] named "HALBERD"
output ATTACKTIMESd[lattackroll [lowest 1 of 2d20] vs ENEMYAC] named "LANCE"

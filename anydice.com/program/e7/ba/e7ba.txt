\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
REGIAAC: 14

ATTACKMOD: 0
DMGBONUS: 0
PROFICIENCY: 0
ACCBONUS: d{3..12}
CRITROLL: 20
ATTACKTIMES: 1
DAMAGE: 1d4 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 2d4 + ATTACKMOD + DMGBONUS
output ATTACKTIMESd[attackroll [lowest 1 of 2d20] + ACCBONUS vs REGIAAC] named "Disadvantage on Attack Rolls"

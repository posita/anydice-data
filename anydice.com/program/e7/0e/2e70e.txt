\attack simulates the average damage of an attack in D&D 5e\
function: attack ROLL:n plus TOHIT:n vs ac AC:n for DICE:d plus FLOAT:n{
if ROLL = 20 {result: DICE + DICE + FLOAT}
if (TOHIT + ROLL) >= AC {result: DICE + FLOAT}
if (TOHIT + ROLL) < AC {result: 0}
if ROLL = 1 {result: 0}
}

\attackcrange accommodates for edge cases with the customization of hit damage effects, miss effects, critical hit damage effects, and expanded critical hit range\
function: attackcrange ROLL:n plus BONUS:n vs ac AC:n hit HIT:d miss MISS:d crit CRIT:d crange CRANGE:n{
    if ROLL = 1 {
        result: MISS
    }
    if ROLL >= CRANGE {
        result: CRIT
    }
    if ROLL + BONUS >= AC {
        result: HIT
    }
    result: MISS
}

\differentattacks vs ac AC ROLLONE plus BONUSONE for HITONE plus FLOATONE and ROLLTWO plus BONUSTWO for HITTWO plus FLOATTWO with specialcrit CRIT\
function: differentattacks vs ac AC:n ROLLONE:n plus BONUSONE:n for HITONE:d plus FLOATONE:n and ROLLTWO:n plus BONUSTWO:n for HITTWO:d plus FLOATTWO:n with specialcrit CRIT:d {
    if (ROLLONE = 20) & (ROLLTWO = 20) {
        result: HITONE + HITONE + FLOATONE + HITTWO + HITTWO + FLOATTWO + CRIT + CRIT
    }
    if (ROLLONE = 20) & (ROLLTWO + BONUSTWO >= AC) {
        result: HITONE + HITONE + FLOATONE + HITTWO + FLOATTWO + CRIT
    }
    if (ROLLONE + BONUSONE >= AC) & (ROLLTWO = 20) {
        result: HITONE + FLOATONE + HITTWO + HITTWO + FLOATTWO + CRIT
    }
    if (ROLLONE + BONUSONE >= AC) & (ROLLTWO + BONUSTWO >= AC) {
        result: HITONE + FLOATONE + HITTWO + FLOATTWO
    }
    if (ROLLONE + BONUSONE >= AC) & (ROLLTWO + BONUSTWO < AC) {
        result: HITONE + FLOATONE
    }
    if (ROLLONE + BONUSONE < AC) & (ROLLTWO + BONUSTWO >= AC) {
        result: HITTWO + FLOATTWO
    }
    result: 0
}

function: test ROLLONE:n for HITONE:d and ROLLTWO:n for HITTWO:d {
    if (ROLLONE = 20) & (ROLLTWO = 20) {
        result: HITONE + HITONE + HITTWO + HITTWO
    }
    result: 0
}

\reroll replaces the result of a given DIE (any die) with a given minimum (MIN) if the result is lower than the given minimum\
function: reroll DIE:n as REROLL:n if less than MIN:n{
if DIE >= MIN {result: DIE}
if DIE < MIN {result: REROLL}
}

\lucky simulates using the Lucky feat on an attack roll. LUCKY always picks the highest die.\
function: lucky DIEA:n DIEB:n{
if DIEA >= DIEB {result: DIEA}
if DIEA < DIEB {result: DIEB}
}

\READ ME\
\DPR in D&D 5e is usually calculated with a 60% chance to hit. this is known as bounded accuracy. this is because enemy AC increases as player attack modifiers increase, making a 60% chance to hit common at almost all levels of play. however, with magic items or class features that increase your attack roll result, such as a +1 Rod of the Pact Keeper or Archery Fighting Style, one can reach 65% and 70% respectively in ideal environments where enemy AC has not been increased by the DM to counter your high accuracy\
\the word output triggers output and can be used multiple times for multiple different outputs\
\functions such as attack must be enclosed in brackets [] to work. a function can be used within another function\
\output will display combined die results as a value (column 1) and the percent chance to get combined die results as a value (column 2 and bar graph)\
\the attack function can be used to calculate DPR as shown below in EXAMPLE attack\


\EXAMPLE attack: output [attack 1d20 plus 1 vs ac 10 for 1d10+1d6 plus 0] named "Eldritch Blast Warlock Level 1"\
\the attack function is called with an attack roll die (1d20), an attack roll modifier (plus 1), an enemy AC (vs ac 10), damage (for 1d10+1d6), and damage modifier (plus 0)\
\the 0 damage row displays the percent chance to miss\

\EXAMPLE expanded crit range attack: output [attackcrange 1d20 plus 1 vs ac 10 hit 1d8 miss 0 crit 2d8 crange 19]\

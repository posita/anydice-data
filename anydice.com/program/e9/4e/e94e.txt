function: avgdmg AC ADV TYPE {
if ADV = 0 {
PHIT: (1d20+8)>AC
}
if ADV = 1 {
PHIT: ([highest 1 of 2d20]+8)>AC
}
if ADV = 2 {
PHIT: ([lowest 1 of 2d20]+8)>AC
}
if TYPE = 0 {
OUTPUT: PHIT*(1d8+5)
}
if TYPE = 1 {
OUTPUT: PHIT*(1d8+3d6+5)
}
if TYPE = 2 {
OUTPUT: PHIT*(2d8+3d6+5)
}
result: OUTPUT
}


\Okay, so put the number right after "avgdmg" equal to the monster's estimated AC.\
\Then, change the number after that to 1 if you have advantage, 2 if disadvantage,\
\and 0 if neither.\
\Then, change the number after that to 0 if it's a normal attack, 1 for sneak attack,\
\and 2 for assassinate (sneak attack w/ auto-crit)\
output [avgdmg 18 1 2]

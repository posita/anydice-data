\
 Blades in the Dark
 0: Things go bad.
 1: Success, but with undesired consequences.
 2: Clean success.
 3: Critical success!
\

function: blades ROLL:s {
 if 1@ROLL = 6 {
  result: 2 + (2@ROLL = 6)
 }
 result: 1@ROLL >= 4
}

output [blades 2@1d6] named "1 cut 1d"
output [blades 2@2d6] named "1 cut 2d"
output [blades 2@3d6] named "1 cut 3d"
output [blades 2@4d6] named "1 cut 4d"
output [blades 2@5d6] named "1 cut 5d"

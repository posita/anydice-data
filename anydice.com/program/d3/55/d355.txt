\ Enemy Armor Class \
AC:14

\ Accuracy Function \
function: acc A:n B:n C:n D:n E:n F:n{
if A=1 {result: 0}
else if A>1 & A<C & A+B < AC {result: 0}
else if A>1 & A<C & A+B > AC {result: D+E+F}
else if A>=C {result: D*2+E+F}
}

\ Re-rolling dice below a certain number \
function: rronedeefour R:n under N:n {

}

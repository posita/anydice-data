\ output [strike ATTACKS vs AC crit THREAT CRITEXTRA CRITDIE dmg DAMAGE EXTRA] named "My Weapon"
This function calculates how much damage you do on an attack
ATTACKS is your attack bonus (e.g. 10), this can include iterative attacks (e.g. {6,1})
AC is the opponent's armor class (e.g. 17)
THREAT is the lower number of the critical threat range (e.g. 19 if your threat is 19-20)
CRITEXTRA is extra damage dice only on a critical hit (e.g. 1d10 for a flaming rune) otherwise leave blank
CRITDIE is an alternate damage to double for crits, e.g. Fatal d10
DAMAGE is the damage you deal with your weapon not including extra dice (e.g. 1d8+2)
EXTRA is extra damage which is not doubled on a crit, otherwise leave blank \

function: strike ATTACKS:s vs AC:n crit THREAT:n CRITEXTRA:d CRITDIE:d dmg DAMAGE:d EXTRA:d {
  SUM: {0}
  loop ATTACK over ATTACKS {
    SUM: SUM + [1d20 plus ATTACK ac AC crit THREAT 2 CRITEXTRA CRITDIE dmg DAMAGE EXTRA]
  }
  result: SUM
}
\ Easier to use versions with default values for omitted fields\

\standard attack, e.g. [strike {15,10,5} vs 23 dmg 2d6]\
function: strike ATTACKS:s vs AC:n dmg DAMAGE:d {
  result: [strike ATTACKS vs AC crit 20 0 DAMAGE dmg DAMAGE 0]
}
\standard attack with extra crit effect, Deadly or property Rune\
function: strike ATTACKS:s vs AC:n crit CRITEXTRA:d dmg DAMAGE:d {
  result: [strike ATTACKS vs AC crit 20 CRITEXTRA DAMAGE dmg DAMAGE 0]
}
\attack with extra non-multiplied damage\
function: strike ATTACKS:s vs AC:n crit dmg DAMAGE:d EXTRA:d{
  result: [strike ATTACKS vs AC crit 20 0 DAMAGE dmg DAMAGE EXTRA]
}
\standard attack with extra crit effect and crit replacement, e.g. Fatal\
function: strike ATTACKS:s vs AC:n crit CRITEXTRA:d CRITDIE:d dmg DAMAGE:d {
  result: [strike ATTACKS vs AC crit 20 CRITEXTRA CRITDIE dmg DAMAGE 0]
}
\attack with keen weapon\
function: strike ATTACKS:s vs AC:n crit keen CRITEXTRA:d dmg DAMAGE:d {
  result: [strike ATTACKS vs AC crit 19 CRITEXTRA dmg DAMAGE 0]
}

\result of a roll, 0-3: crit fail, fail, success, crit success\
function: result ROLL:n MOD:n DC:n {
  if (ROLL + MOD < DC-10) {
     RES: 0
  } else if(ROLL + MOD < DC) {
     RES: 1
  } else if(ROLL + MOD < DC + 10) {
     RES: 2
  } else {
     RES: 3
  }
  if (ROLL = 1) { RES: RES-1 }
  if (ROLL = 20) { RES: RES+1 }
  if (RES < 0) { result: 0 }
  else if (RES > 3) { result: 3 }
  else { result: RES }
}
 
\individual roll calculation\
function: ROLL:n plus ATTACK:n ac AC:n crit THREAT:n MULT:n CRITEXTRA:d CRITDIE:d dmg DAMAGE:d EXTRA:d {
  RES: [result ROLL ATTACK AC]
  if (RES = 3) { result: [crit MULT CRITDIE] + EXTRA + CRITEXTRA } \crit damage\
  else if (RES = 2) {result: (ROLL + ATTACK >= AC) * (DAMAGE + EXTRA)} \regular damage\
  else { result: 0 }
}
function: crit MULT:n DAMAGE:d {
  result: (DAMAGE * MULT)
}

\Damage from a saving roll spell
SPELLS: The spells' DC(s)
SAVE: Saving throw modifier of target
DAMAGE: Damage on a fail
Does half damage on success, double on critical fail
\
function: cast SPELLS:s vs SAVE:n dmg DAMAGE:d {
  SUM: {0}
  loop SPELL over SPELLS {
    SUM: SUM + [1d20 spell SPELL save SAVE DAMAGE]
  }
  result: SUM
}

function: ROLL:n spell SPELL:n save SAVE:n DAMAGE:d {
  RES: [result ROLL SAVE SPELL]
  if (RES = 3) { result: 0 }
  else if (RES = 2) { result: DAMAGE/2 }
  else if (RES = 1) { result: DAMAGE }
  else { result: DAMAGE*2}
}

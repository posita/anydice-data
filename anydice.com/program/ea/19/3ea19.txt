\{ "1": "Full Success", "0": "Partial Success", "-1": "Failure" }\
function: pbta X:n {
   if (X >= 10) { result:  1 }
   if (X <=  6) { result: -1 }
   result: 0
}

function: swordcrest ROLL:n with BONUS:n {
   if (ROLL = 12) { result:  1 }
   if (ROLL =  2) { result: -1 }

   X: ROLL + BONUS

   if (X >= 15) { result:  1 }
   if (X <= 10) { result: -1 }
   result: 0
}


output [pbta 2d6 - 3]
output [swordcrest 2d6 with 1]

\
   Natural Snake Eyes and Natural Boxcars are always a failure and a success, respectively, irrespective of modifiers and fictional positioning.
   Otherwise, 10 or less is a failure, 15 or more is a full success, and anything in the middle is a partial result, or a success with consequences.
   Players can stack advantages (or suffer stacked disadvantages) limited to 4 (each). Each (dis)advantage corresponds to a +1 to the roll. (Dis)advantages can only come from circumstantial elements (e.g. high ground, poison an enemy, leverage, etc), never from playbook moves.
   Major classes max out at level 5, while minor classes at level 3. Background playbooks (I'm still thinking about these) do not have classes and do not need to be leveled up.
   This means that at lower level, the game is harder than a standard PbtA, and at higher levels it more or less matches the best-case scenario of standard PbtA. For example, in SC, a character at level 5 and attribute 4 is rolling 2d6 + 9 (5 + 4), which closely resembles PbtA's 2d6 + 4 (max attribute value). While at lower level, in SC, 2d6 + 1 (level 1 and 0 attribute) is equivalent to PbtA's 2d6 - 3. Playing SC is like playing PbtA but starting with negative modifiers.
   This, hopefully, will incentivize players to seek advantage first and strategize instead of barge into a scene, guns blazing.

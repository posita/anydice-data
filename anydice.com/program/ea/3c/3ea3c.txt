function: die A:s die B:s add C:n vs D:n plus E:n step F:n {
if A = B { Y: 1}
if A + B = 2 { Y: -1 }
if A = B { Z: A + B + C + E }
else { Z: A + B + E }
if Z > D + F { result: 4 + Y}
if Z > D { result: 3 + Y }
if Z > D - F { result: 2 + Y}
result: 1 + Y
}

output [ die d10 die d10 add 10 vs 10 plus 18 step 10 ] named "degrees of success"

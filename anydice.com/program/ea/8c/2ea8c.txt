function: if CONDITION:n then A else B {
  if CONDITION { result: A } else { result: B }
}

AC: 20
ATKBON: 7
DAM: 1d4+2d6+3d6+5

DROLLA: [highest 1 of 2d20]
ROLLA: d20
DROLLB: [highest 1 of 2d20]
ROLLB: d20

CRA: 2d4+5+4d6+6d6
CRB: 2d4+5+4d6+6d6

ATA: [if ROLLA+ATKBON > AC then DAM else 0]
ATB: [if ROLLB+ATKBON > AC then DAM else 0]

FINALA: [if ROLLA = 20 then CRA else ATA]
FINALB: [if ROLLB = 20 then CRB else ATB]

output FINALA + FINALB

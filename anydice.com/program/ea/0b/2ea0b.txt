Modifier MOD definition:
1@ +/- Threat dice  (Lethality/Blunt;  1 by default)
2@ +/- STR modifier (Brutal/Temperate; 1 by default)
\

function: ATK:n with bonus B:n to hit TGT:n for DAM:n with MOD:s
{
  C:0 \Total Dice Count\
  T:0 \Threat Dice Count\
  D:0 \Dice Scale\
  \Set up ATK Dice\
       if ATK = 1{C:2  D:10}
  else if ATK = 2{C:3  D: 8}
  else if ATK = 3{C:4  D: 6}
  else if ATK = 4{C:6  D: 4}
  else if ATK = 5{C:8  D: 3}
  else if ATK = 6{C:12 D: 2}
  T:1 + 1@MOD
  \Cleanup, such as out of bounds threat count\
  if T < 0 {T: 0} else if T > C {T: C}

  \Roll to-hit dice\
  TOHIT:B
  CRT:0
  \Start with the thread dice\
  loop N over {1..T}
  {
    A: 1dD
    CRT: CRT + [flag crit A D]
    TOHIT: TOHIT + A
  }
  \Then the rest of the dice\
  TOHIT: TOHIT + (C-T)dD

  \Do we hit the target?\
  HIT: (TOHIT > TGT)
  
  \How much damage do we do?\
  R: DAM
  \STR Modifier Multiplier\
  MULT: 1 + 2@MOD
  if MULT < 0 {MULT: 0}
  R: R+(MULT * STR)
  \Now + crits (1d4 per crit)\
  R: R + CRTd4
  result: (R * HIT)
}

function: flag crit R:n D:n
{
  if R = D {result: 1} else {result: 0}
}

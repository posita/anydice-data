\**** Damage calculator ****\
\** ATTACKMOD is STAT bonus **\
\** ACCBONUS is any accuracy bonus or penalty, such as GWM feat or weapon bonus **\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

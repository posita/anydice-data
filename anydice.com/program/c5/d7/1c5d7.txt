\**** BASIC DAMAGE CALCULATOR ****\

\** Attack Roll Function **\
function: attackroll ROLL:n vs AC:n {
 if ROLL + PROFICIENCY + ABILITYMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\** Attack looped against enemy AC from 15-20 **\
ENEMYAC: d{15..20}

\** Edit Here **\
ABILITYMOD: 4
DMGBONUS: 0
PROFICIENCY: 3
ACCBONUS: 0
CRITROLL: 20
ATTACKTIMES: 1
DAMAGE: 1d8 + ABILITYMOD + DMGBONUS

\** Output with Normal, Advantage and Disadvantage **\
output ATTACKTIMESd[attackroll d20 vs ENEMYAC] named "normal ability check"
output ATTACKTIMESd[attackroll [highest 1 of 2d20] vs ENEMYAC] named "ability check with advantage"
output ATTACKTIMESd[attackroll [lowest 1 of 2d20] vs ENEMYAC] named "ability check with disadvantage"

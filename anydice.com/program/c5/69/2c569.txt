\Roll twice, keep the roll which is closest to either 7 or 12, favouring 7 if equal\
function: lowhighsevtwe C:s vs B:s 
 {
 if C > B {if 11-C < B-8 {result: C} result: B}
           if 11-B < C-8 {result: B} result: C
 }

\Reroll until all results are from 7 to 12\
function: rrsevtwe A:n
 {
 if A<=12 {if A>=7 {result: A} result: [rrsevtwe A]}
           result: [rrsevtwe A] 
 }

\Roll twice, keep the roll which is closest to either 3 or 12, favouring 3 if equal\
function: lowhighthrtwe C:s vs B:s 
 {
 if C > B {if 10-C < B-5 {result: C} result: B}
           if 10-B < C-5 {result: B} result: C
 }

\Reroll until all results are from 3 to 12\
function: rrthrtwe A:n
 {
 if A<=12 {if A>=3 {result: A} result: [rrthrtwe A]}
        result: [rrthrtwe A]     
 }

\**** Damage calculator normal attack ****\

function: attackroll ROLL:n vs DEF:n {
 if ROLL >= CRITROLL { result: 2} 
 if ROLL <= 2 { result: 0 }
 if ROLL + ATTACKBONUS >= DEF { result: 1}
 result: 0
}

\looped against enemy DEF\
ENEMYDEF: d{12}

ATTACKBONUS: 4
RAGEBONUS: 0
CRITROLL: 12
WPNDAMAGEA: 1
output 6d[attackroll 2d6 vs ENEMYDEF] named "normal attack"
output 2d6 + 4 +16 + 1 named "normal attack"

function: mindamage A:n{
  if A > 3 {result:A}
  if A < 1 {result:0}
  result: 3
}

function: advexplode A:n B:n{  \Use the form [advexplode [highest/lowest X of (dice)] (die total e.g. 1d4 = 4)]\
  TOTAL: A
  if A = B {TOTAL: B+[explode 1dB]}
  result: TOTAL
}

output [explode 1d20] + 2d[explode 1d8] named "Attribute 6"
output [mindamage [explode 1d20] + [explode 1d6]-16] named "Summon Attack (2)"

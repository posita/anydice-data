function: dupont POS:s vs NEG:n {
  R: POS < NEG \ number of values in POS:sequence/array/list that is lower than NEG \
  if NEG = #POS@POS { result: 0 } \ if NEG and the lowest value in POS are the same, result is zero; #POS = number of values in POS, 1@ = highest, 2@ second highest, #POS@ is lowest\
  if R = 0 { result: -NEG }       \ NEG is the smallest value, result is the negative die \
  result: (#POS-R+1)@POS                   \ otherwise the result is the highest positive die that is lower than NEG \
}

TEN: 10 \a zero-to-9 d10 in contrast with 1-10 d10\

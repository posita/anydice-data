\ Definisce una funzione per ottenere il risultato minimo tra le due combinazioni \
function: mincombination A:n B:n {
  C: 10 * A + B
  D: 10 * B + A

  \ Se il risultato Ã¨ 00, consideralo 100 \
  if C = 0 { result: 100 }
  if D = 0 { result: 100 }

  result: [lowest of C and D]
}
\ Simula il lancio di due d10 \
E: d10 - 1
F: d10 - 1

\ Applica la funzione ai risultati dei due dadi \
RESULT: [mincombination E F]

\ Mostra la distribuzione dei risultati \
output RESULT+200 named "Distribuzione con scelta ottimale"

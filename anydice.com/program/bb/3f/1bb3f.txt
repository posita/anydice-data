\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
if ROLL >= CRITROLL { result: CRITDAMAGE }
if ROLL = 1 { result: 0 }
if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..25}

ATTACKMOD: 4
DMGBONUS: 0
PROFICIENCY: 2
ACCBONUS: 0
CRITROLL: 19
ATTACKTIMES: 3
DAMAGE: 2d6+1d6+2
CRITDAMAGE: DAMAGE*2
output ATTACKTIMESd[attackroll d20 vs ENEMYAC] named "Scorching Ray Zappy"
output 4d4+4+4d6+8 named "Magic Missile Level 2"

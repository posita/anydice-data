\**** Damage calculator normal Vs advantage ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15}


ATTACKMOD: 3
DMGBONUS: 0
PROFICIENCY: 2
ACCBONUS: 0
CRITROLL: 19
ATTACKTIMES: 4
DAMAGE: 3d4 + DMGBONUS
CRITDAMAGE: 3d4
output ATTACKTIMESd[attackroll [lowest 1 of 2d20] vs ENEMYAC] named "Rogue"

\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..20}

ATTACKMOD: 7+1\plus 1 from gloves of dex\
DMGBONUS: 2+14+1d4
PROFICIENCY: 4
ACCBONUS: 0
CRITROLL: 16
ATTACKTIMES: 1
DAMAGE: 4d8 + 1d6 + ATTACKMOD + DMGBONUS
CRITDAMAGE: 4d8 + 2d6 + ATTACKMOD + DMGBONUS
A: ATTACKTIMESd[attackroll [highest 1 of 2d20] vs ENEMYAC]

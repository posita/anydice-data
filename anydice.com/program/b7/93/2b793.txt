
function: DIE:n TH:n AC:n {
if DIE = 20 {result: 2} 
if DIE+TH>=AC {result: 1}
result: 0
}

function: ATT:n attacks TOHIT:n tohit ADV:n bool advantage AC:n ac{
C: 0
loop N over {1..ATT} {
C: C + [1@(ADV+1)d20 TOHIT AC]
}
result: C
}
function: output H:n N:n die D:n plus B:n{
result: (H*N)dD + H*B
}

HITS: [10 attacks 8 tohit 1 bool advantage 19 ac ]
output [output HITS 1 die 4 plus 4]
output HITS

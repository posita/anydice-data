function: save ROLL:n plus MODIFIER:n against DC:n for DAMAGE:d {
    if (ROLL + MODIFIER >= DC) {
        result: DAMAGE
    } else {
        result: DAMAGE / 2
    }
}

output [save 1d20 plus 3 against (8+3+2) for 8d6] named "Fireball"
output [save 1d20 plus 3 against (8+3+3) for 5d6] named "Song of Roast"

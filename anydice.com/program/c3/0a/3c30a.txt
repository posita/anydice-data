\ Function to find the two highest different values  \
function: highest two different of A:s {  
  X: 0  
  Y: 0  
  loop N over A {  
    if N > X {  
      Y: X  
      X: N  
    } else if N > Y & N != X {  
      Y: N  
    }  
  }  
  result: {X, Y}  
}  

\ Function to sum all dice that match the highest two values\  
function: sum matching of A:s in B:s {  
  TOTAL: 0  
  loop N over B {  
    if N = A@1 | N = A@2 {  
      TOTAL: TOTAL + N  
    }  
  }  
  result: TOTAL  
}  

\ Function to roll X dice and compute the correct result  \
function: compute result for Q:n {  
  DICE: Qd6  \ Rolls X six-sided dice  \
  HIGH: [highest two different of DICE]  \ Finds the two highest different values  \
  BASE: HIGH@1 + HIGH@2  \ Adds those two highest values  \
  EXTRA: [sum matching of HIGH in DICE]  \ Adds all matching dice\
  result: BASE + EXTRA  \ Final total \  
}

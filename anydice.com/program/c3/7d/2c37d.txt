\
FlyteStorm's dice system
output 1 is resolve 0
output 2 is resolve 1
output 3 is resolve 2
result 2 is a strong hit (beat by 2 or more)
result 1 is a weak hit within one point of adversary)
result 0 is a miss (lose by 2 or more)
Default dice are 1d8 for the player and 1d6 for the adversary
Normal Table or Transposed Graph are good views
\

function: flytestormdice ROLL:n {  
if ROLL >= +2 { result: 2 } \beat by 2\
if ROLL >= -1 { result: 1 } \within 1 point\
result: 0 \miss by 2 or more\
}

loop RESOLVE over {0..2} {  
output [flytestormdice 1d8 - 1d6 + RESOLVE] \replace these with the player and GM die\
}

\ Define the function to handle the reroll \
function: reroll DIE:d if less than THRESHOLD:n {
  if DIE < THRESHOLD { result: d6 }
  result: DIE
}

\ Define our custom reroll die \
REROLL_DIE: [reroll d6 if less than 6]

\ Output the number of 6s rolled out of 4 dice \
output 4d(REROLL_DIE = 6) named "Number of 6s"

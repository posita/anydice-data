\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{17}

ATTACKMOD: 3
PROFICIENCY: 3
ATTACKTIMES: 1
DAMAGE: 4d10 + 12 + 4d6
output ATTACKTIMESd[attackroll d20 vs ENEMYAC] named "Eldritch Blast + Agonizing blast + Hex"

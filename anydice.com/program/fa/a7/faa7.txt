\ COME FUNZIONA:\
\  1- I due giocatori buttano un numero da 0 a 10 con le due mani (da 0 a 10 dita)\
\  2- Si sommano i due numeri \
\  3- Se il risultato Ã¨ 10 o piÃ¹ si toglie 10 dal risultato\
\  4- Si ottiene un numero da 0 a 9\

\  6- I due risultati si compongono a ottenere un valore percentile:\

\  7- Si divide il valore percentile per 5 arrotondando per eccesso, a ottenere un numero da 1 a 20\

\ Funzioni usate sotto per fare i calcoli \
function: sum A to B { result: A + B }
function: mod C:n by E:n { loop N over {1..10} { if C >= E { C: C - E } } result: C }
LANCIO: d{0..10}

\ #1 - #4 \
DECINE: [sum LANCIO to LANCIO]
DECINE: [mod DECINE by 10]

\ #5 (si ripete #1 - #4) \
UNITA: [sum LANCIO to LANCIO]
UNITA: [mod UNITA by 10]

PERCENTILE: [sum DECINE * 10 to UNITA]

\ il +1 serve per arrotondare per eccesso (AnyDice fa sempre i conti per difetto) \
RISULTATO: (PERCENTILE / 5) + 1

output RISULTATO named "RISULTATO"

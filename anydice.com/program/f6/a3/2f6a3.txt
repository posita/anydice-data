  SUCCESS: [count 6 in LIMITd6]
  result: [resolve helper LIMIT SUCCESS REROLL]

function: resolve helper LIMIT:n SUCCESS:n REROLL:n {
  if SUCCESS >= 3 {
    result: 1
  } else {
    LIMITREROLL: [lowest of REROLL and LIMIT - SUCCESS]
    result: SUCCESS + [count 6 in LIMITREROLLd6] >= 3
  }
}
output [resolve 8 reroll 0]
The calculator takes two arguments, which can be changed on the last line:

resolve: how many dice are being rolled in the Blessings of Khorne dice pool.

reroll: how many dice can be rerolled with abilities like the Icon of Khorne.

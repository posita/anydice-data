function: dos D:n per N with T {
 if D > T { result: 1+(D-T)/N}
 if D = T { result: 1}
 if D < T {result: (D-T)/N-1}
}
DSA: [dos 1d100 per 10 with 30]
DSB: [dos 1d100 per 10 with 45]
DSC: [dos 1d100 per 10 with 60]

output 3dDSA named "sympathetic"
output 2dDSB named "confident"
output 1dDSC named "threatening"

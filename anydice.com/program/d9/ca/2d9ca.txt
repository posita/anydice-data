\Roll twice, keep the roll which is closest to either 3 or 12, favouring 3 if equal\
function: lowhighthrtwe C:s vs B:s 
 {
 if C > B {if 12-C < B-3 {result: C} result: B}
           if 12-B < C-3 {result: B} result: C
 }

\Reroll until all results are from 3 to 12\
function: rrthrtwe A:n
 {
 if A<=12 {if A>=3 {result: A} result: [rrthrtwe A]}
        result: [rrthrtwe A]     
 }

output [lowhighthrtwe [rrthrtwe {2,3,4}@4d4] vs [rrthrtwe {2,3,4}@4d4]]

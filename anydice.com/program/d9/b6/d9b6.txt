[bindtryagain X Y Z] - binding with "second chanced" resistance roll
[compare X Y] - X dice or dices of "attacker" (1), Y dice or dices of "defender" (-1);

[cmpsucc X Y] - (X->1 ; Y -> -1); compared roll only displaying success/failure/draw
output X - X number, dice or dices, mathematical operation (+-/*^)
output X named "Y" - output table for X named Y

function: ROLL:n gwf REROLL:d reroll SEQUENCE:s{
  if [SEQUENCE contains ROLL] {
    result: REROLL
  }
  else {
    result: ROLL
  }
}

STR: 5
DIE_ONE: [d6 gwf d6 reroll {1,2}]
DIE_TWO: [d6 gwf d6 reroll {1,2}]
DIE_THREE: [d6 gwf d6 reroll {1,2}]
DIE_FOUR: [d6 gwf d6 reroll {1,2}]

output (DIE_ONE+DIE_TWO+STR)*2 named "Maul"
output (DIE_ONE+DIE_TWO+DIE_THREE+STR)*2 named "Magic Maul"
output (DIE_ONE+DIE_TWO+DIE_THREE+DIE_FOUR+STR)*2 named "Giant Magic Maul"  \Doubled damage for 2 attacks\

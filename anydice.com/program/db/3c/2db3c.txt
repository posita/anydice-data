RANGE: 30

function: clamp N:n between MIN:n and MAX:n {
  if N > MAX { result: MAX }
  if N < MIN { result: MIN }
  result: N
}

DIE: d12
DIEMAX: [maximum of DIE]
DIEMID: DIEMAX / 2

\
  There are simpler ways to define this but I want to validate
  the procedure: 
    1) Roll first die, if min or max value roll again. On
       subsequent rolls only roll again on max value.
    2) Total all dice and subtract total number of dice rolled.
    3) If *first* roll was a one, treat value as negative.

    Roll first die.
      * If it is a one, roll again treating ones as normal
        numbers (see below for rolling again on max value.) The
        result is the value - 1 as a negative number.
      * If it is the max value for the die, roll again (also
        rolling an additional die for each max value.) Total
        all dice plus one and subtract the number of *additional*
        dice rolled.
      * Otherwise, the result is the number rolled.
  Examples:
    Roll(s)  Total  #Dice  Result
     3          3      1       2
     6,1        7      2       5
     6,6,2     14      3      11
     1,4        5      2      -3
     1,6,5     12      3      -9
\
function: roll {
  result: [roll DIE]
}
function: roll R:n {
  if R = 1 { result: -(R - 1 + [roll add DIE]) }
  if R = DIEMAX { result: R - 1 + [roll add DIE] }
  result: R - 1
}
function: roll add R:n {
  if R = DIEMAX { result: R - 1 + [roll add DIE] }
  result: R - 1
}

output [clamp [roll]-[roll] between -RANGE and RANGE] named "chain [DIE] vs"
output [clamp [roll]-DIEMID between -RANGE and RANGE] named "chain [DIE]-[DIEMID]"

DZFIVE: d{0..5}
function: test {
  result: [test DIE]
}
function: test N:n {
  if N = DIEMAX { result: DIEMAX + [explode DZFIVE] }
  if N = 1 { result: 1 - [explode DZFIVE] }
  result: N
}
set "explode depth" to 10
TESTMID: DIEMID+1
output [clamp [test]-TESTMID between -RANGE and RANGE] named "test x12-[TESTMID]"

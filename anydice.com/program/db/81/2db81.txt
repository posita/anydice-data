\Input desired Speed, Defense, Attack Power, and Accuracy Check roll.
Modifiers can be added if necessary.
Outputs -1 for Miss, 0 for Graze, and 1 for Hit.\


SPD: 16-3
DEF: 16+7
ATK: 2d6+16
ACC: 2d6+6+0
HIT: 1


function: attack calc with A:n B C:n D{
X: C
HIT: 1
if A < B {
X: X - 6
HIT: HIT - 1
}

if X < D {
HIT: HIT - 1
}
result: HIT
}

output [attack calc with ACC SPD ATK DEF]

\
H&G  2d12 vs. 10 to 4, roll EQUAL or HIGHER.
Critical: if dice are equal and both successes.
Stats range = 10-4 (avg : 7)

 -1: Miss.
 0: Success, but with undesired consequences.
 +1: Clean success.
 +2: Critical success!
\

function: roll A:s with DICE {
 R: 0
 HALFDICE: DICE/2
 S: [count {6} in A]
 Z: [count {1} in A]
 if Z > S {
   R: -1
 }
 if S > 0{
   R: 1
 }
 if S > 1{
   R: 2
 }
 result: R
}

loop P over {1..10} {
 output [roll Pd6 with P] named "[P]"
}

\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC + 5 { result: STYLEDAMAGE }
 if ROLL + PROFICIENCY + ATTACKMOD + ACCBONUS >= AC { result: DAMAGE }
 result: 0
}

\looped against enemy AC from 15-20\
ENEMYAC: d{15..20}

ATTACKMOD: 5
DMGBONUS: 0
PROFICIENCY: 5
ACCBONUS: 0
CRITROLL: 18
DAMAGE: 2d8 + ATTACKMOD + DMGBONUS + 1d6
STYLEDAMAGE: 3d8 + ATTACKMOD + DMGBONUS + 1d6
CRITDAMAGE: 4d8 + ATTACKMOD + DMGBONUS + 2d6
output [attackroll 1d20 vs ENEMYAC] + [attackroll 1d20 vs ENEMYAC] + [attackroll 1d20 vs ENEMYAC] named "Scribble Horde Breaker, Hunter's Mark"

DMGBONUS: 0

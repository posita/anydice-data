\Bone die    2/6        the default\
BONE:   {1:2,0:4}

\Cursed die  3/6        also "loot die"\
CURSED: {1:3,0:3}

\Chaos die   4/6        from tomes\
CHAOS:  {1:4,0:2}

\Skaven die  6/6        from grimoires\
SKAVEN: {1:6}

function: L loot T tome G grimoire {
  B: 7
  DICE: d{}
  if L > 0 {
    DICE: DICE + LdCURSED
    B: B - L
  }
  if T > 0 {
    DICE: DICE + TdCHAOS
    B: B - T
  }
  if G > 0 {
    DICE: DICE + GdSKAVEN
    B: B - G
  }
  result: DICE + BdBONE
}
\
So, Ranald's Bones gives you 7 dice
These are first only 'Bone Dice'

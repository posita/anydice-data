function: num of successes from A:n {
 TIER_SIX : 33
 TIER_FIVE : 27
 TIER_FOUR : 22
 TIER_THREE : 15
 TIER_TWO : 8
 TIER_ONE : 3
 if A > TIER_SIX { result: 6 }
 if A > TIER_FIVE { result: 5 }
 if A > TIER_FOUR { result: 4 }
 if A > TIER_THREE { result: 3 }
 if A > TIER_TWO { result: 2 }
 if A > TIER_ONE { result: 1 }
}
MOD : 4
DIE : 4
CHECKS : 30
SUCCESSES : 0
RESULT: 1d20+MOD
loop X over {1:CHECKS}{
SUCCESSES : SUCCESSES + [num of successes from RESULT]
}
output SUCCESSESdDIE

\**** Damage calculator ****\

function: attackroll SAVINGTHROW:n vs SPELLDC:n {
 if SAVINGTHROW >= SPELLDC { result: SUCCESSFULSAVE }
 if SAVINGTHROW < SPELLDC { result: FAILEDSAVE }
}


SAVINGTHROW: 1d20

SUCCESSFULSAVE: 2d8 + 5d8

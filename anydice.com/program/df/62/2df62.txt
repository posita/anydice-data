\
Kult Die Calculator
-----------------------------------------------------
A result of "1" means "Success"
A result of "0" means "Success with Complications"
A result of "-1" means "Failure"

Input Values:
MOD: Anything added to the roll to modify it.
\

\Input Values\
MOD: 0

\PROGRAM STARTS HERE\

function: kult VAL:n {
result: [kulthelp 2d10 VAL]
}

function: kulthelp ROLL:s VAL:n {
if ROLL+VAL>=15 {result: 1}
else if ROLL+VAL>=10 {result: 0}
else {result: -1}
}

output [kult MOD] named "Chance of Succcess"

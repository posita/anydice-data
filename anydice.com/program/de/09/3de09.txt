function: A:n B:n roll plus extra C:n if crit {
if A = 20 {result: B + C}
 result: B
}

function: save for prone A:n B:n C:n {
if A < 16 { if B > 19 {result: C+6} result:0 }
result: C
}

output 1d12 + 1 +1d8 + [save for prone (1d20 + N) [highest of 1d20+6 and 1d20+6] (1d12+1)]

\ 
* The basic pbta style roll
* ROLL: the dice you roll
* LOW: below or equal is failure
* HIGH: above or equal is clean success
\ 
function: pbta ROLL:n LOW:n HIGH:n {
  if ROLL <= LOW {
    result: -1
  }
  if ROLL >= HIGH {
    result: 1
  }
  result: 0
}
output [pbta 2d6 6 10]

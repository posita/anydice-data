\ to get a reroll effect, create a custom function that only includes results for the values you want to keep \

function: ignore below N:n for ROLL:n {
 if N < ROLL { result: ROLL }
}

function: guess from ROLL:n
{
 if n == ROLL 
 {
  result: 5
 }
 else
 {
  result:0
 }
}

output [ignore below 2 for 1d6+1]
output [ignore below 3 for 1d4+2]
output [ignore below 1 for 1d4]

output 1d6+2

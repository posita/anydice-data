\**** Weapon Master Damage calculator normal attack ****\

function: attackroll ROLLA:n with ROLLB:n vs DEF:n {
 if {ROLLA + ROLLB} <= 2 { result: 0 }
 if ROLLA = ROLLB { result: (ROLLA + ROLLB + ATTACKBONUS - DEF + BONUSDMG + WPNDAMAGEA)*2 + CINDERB} 
 if {ROLLA + ROLLB} + ATTACKBONUS >= DEF { result: ROLLA + ROLLB + ATTACKBONUS - DEF + BONUSDMG + WPNDAMAGEA + CINDERB}
 result: 0
}

\looped against enemy DEF\
ENEMYDEF: d{10}

ATTACKBONUS: 4
BONUSDMG: 0
CINDERB: 0
CRITROLL: 12
WPNDAMAGEA: 30
output [attackroll 1d6 with 1d6 vs ENEMYDEF] named "normal attack"
output 2d6

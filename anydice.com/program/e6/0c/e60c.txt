                                                \****************************************************************************\
EAC: 18                                         \ Enemy AC                                                                   \
GHM: 9                                          \ Global Hit Modifier                                                        \
GCT: 19                                         \ Global Crit Threshold                                                      \
HIT: 1d20                                       \ Hit Dice                                                                   \
                                                \****************************************************************************\
function: acc A:n B:n C:n D:n E:n F:n{          \ Begin ACC function                                                         \
if A=1 {result: 0}                              \ if 1d20 equals 1, miss                                                     \
else if A>1 & A<C & A+B < EAC {result: 0}       \ if 1d20 plus attack mod is less than enemy AC, miss                        \
else if A>1 & A<C & A+B > EAC {result: D+E+F}   \ if 1d20 plus the total attack dice is more than enemy AC, calculate damage \
else if A>=C {result: D*2+E+F}                  \ if 1d20 equals 20, double dice and add damage modifiers.                   \
}                                               \ End ACC function                                                           \
                                                \****************************************************************************\

                                                \***********************\
function: gwf A:n B:n{                          \ Great Weapon Fighting \
   if A <= 2 { result: B } else {result: A}     \ Great Weapon Fighting \
}                                               \ Great Weapon Fighting \
                                                \***********************\

\***********************************************************************\
\        Example: output [acc HIT GHM GCT 1d6 5 0]                      \
\***********************************************************************\

output [acc HIT GHM GCT [gwf 1d8 1d8]+[gwf 1d8 1d8]+[gwf 1d8 1d8] 5 0]

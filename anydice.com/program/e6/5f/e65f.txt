\**** Stealth vs Active Perception calculator ****\

function: attackroll ROLL:n vs PERCEPTIONROLL:n {
 if ROLL + PROFICIENCY + DEXMOD >= PERCEPTIONROLL + CWISMOD { result: 1 }
 if ROLL + PROFICIENCY + DEXMOD < PERCEPTIONROLL + CWISMOD { result: 0 }
}

\The value of 1 represents the percentage of Regia succeeds his Stealth Check, and the value of 0 represents the percentage the Cobalt succeeds his perception check.\

\looped against enemy AC from 15-20\
PERCEPTION: d{1..20}

\**Regia's Active Stealth**\
DEXMOD: 0
PROFICIENCY: 0
ACCBONUS: 0

\**Cobalt's Active Perception**\
CWISMOD: 4
CPROFICIENCY: 0

NUMBEROFTIMES: 1

\Regia has a 66% to get caught and noticed by the Cobalt\
\Regia has a 34% chance to successful sneak away without being noticed by the Cobalt\

output NUMBEROFTIMESd[attackroll 1d20 vs PERCEPTION] named " Active Stealth vs Active Perception"

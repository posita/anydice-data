\**** Damage calculator ****\

function: attackroll ROLL:n vs AC:n {
 if ROLL >= CRITROLL { result: CRITDAMAGE } 
 if ROLL + ACCBONUS >= AC { result: DAMAGE }
 result: MISSDAMAGE
}


ENEMYAC: d{10..22}

ACCBONUS: 9
CRITROLL: 20
ATTACKTIMES: 2
DAMAGE: 1d6 + 1d4 + 5 + 3 + 10
CRITDAMAGE: 2d6 + 2d4 + 5 + 3 + 10
MISSDAMAGE: (1d6 + 1d4 + 5) / 2
NOVA: 24 + [highest 2 of 4d6] + 2d6
output ATTACKTIMESd[attackroll 1d20 vs ENEMYAC] + NOVA named "Consistent"

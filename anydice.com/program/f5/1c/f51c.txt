\
 Requested mechanic Silhoutte by Dreampod 9:

 Roll Xd6, take the highest die.
 If it is 1-5, it is your result, otherwise, if it is 6,
 your result is 6 + 1 per each other die that shows six.
\

function: dsixdungeon ROLL:s{
 if 1@ROLL = 1 {
  result: [count 1 in ROLL]
 }
 result: 1@ROLL + [count 1 in ROLL]
}

loop D over {1..6}{
 output [dsixdungeon Dd6] named "[D]d"
}

\
ADVANTAGE/REROLL
H&G  1d12 vs. 10 to 4, roll EQUAL or HIGHER.
Critical: if natural 12.
Stats range = 10-4 (avg : 7)

 -1: Miss.
 +1: Clean success.
 +2: Critical success!
\

function: roll A:s and B:s vs S:s {
 R: -1
 if A >= S {
   R: 1
 }
 if A = 12 {
   R: 2
 }
 if R < 1 {
   if B >= S {
     R: 1
   }
   if B = 12 {
     R: 2
   }
 }

 result: R
}

loop P over {0..6} {
 CR: 10-P
 output [roll 1d12 and 1d12 vs CR] named "[CR]"
}

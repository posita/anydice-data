\
ADVANTAGE ROLLS

H&G  1d12 vs. 10-stat, roll HIGHER.
Critical: if natural 12.
Stats range = 0-7 (avg=4)

 -1: Miss.
 +1: Clean success.
 +2: Critical success!
\

function: roll A:s and B:s vs S:s {
 R: -1
 if A > S {
   R: 1
 }
 if B > S {
   if R < 1 {
     R: 1
   }
 }
 if A =12 {
   R: 2
 }

 result: R
}

loop P over {1..7} {
 output [roll 1d12 and 1d12 vs 10-P] named "[P]"
}

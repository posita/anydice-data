function: HIT:n to hit vs ac AC:n dealing DAMAGE:n critting on CRIT:n
{
 if HIT >= CRIT    { result: DAMAGE * 2 }  \checks to see if d20 rolled the crit value or higher\
 else if HIT >= AC { result: DAMAGE }      \checks to see if d20 rolled the AC value or higher\
 else              { result: 0 }           \if the d20 doesn't meet either the crit or AC value, deal 0 damage\
}

\notes: HIT must always be an unmodified d20, else the calculator will assume you have a higher crit chance than you do\
\       To calculate hit chance properly type (AC - your hit chance) in place of the AC value\

output [d20 to hit vs ac (16-6) dealing 2d6+5 critting on 20]



function: explode ROLL:n on DIE:n {
  if ROLL = DIE 
    { result: DIE + [explode d(DIE)] }
  if ROLL = 2
    { result: 2 + [explode d(DIE)] }
 result: ROLL
}

BETTERDEEFOUR: [explode d4 on 4]

\
H&G  2d12 vs. 10 to 4, roll EQUAL or HIGHER.
Critical: if dice are equal and both successes.
Stats range = 10-4 (avg : 7)

 -1: Miss.
 0: Success, but with undesired consequences.
 +1: Clean success.
 +2: Critical success!
\

function: roll A:s and B:s vs S:s {
 R: -1
 if A >= S {
   R: R+1
 }
 if B >= S {
   R: R+1
 }
 if A = B {
   if R = 1 {
     R: 2
   }
 }

 result: R
}

loop P over {0..6} {
 CR: 10-P
 output [roll 1d12 and 1d12 vs CR] named "[CR]"
}

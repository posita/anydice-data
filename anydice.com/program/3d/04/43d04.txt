function: highest of P:s with D:s drop C:n {
  I: 1  \ index of the highest p die still kept \
  J: 1  \ index of the highest d die still kept \

  loop K over {1..C} {
    if I > #P { result: 0 }
    else if J > #D { I: I + 1 }
    else if I@P > J@D { I: I + 1 }
    else { J: J + 1 }
  }

  if I > #P { result: 0 }
  else { result: I@P > 3 }
}

output [highest of 8d6 with 0d6 drop 5] named "result"

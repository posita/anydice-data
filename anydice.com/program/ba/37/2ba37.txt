\ An example of using special dice and counting which face shows up on each \
\ Change the numbers in the collections to use different numbers on your special dice \
\ Change the numbers in I loop to count different faces \
\ Change the numbers in J loop to roll a different number of the special die \
\ It's probably possible to do special combinations doing boolean functions, but you should stop right there and ask yourself if players are willing to put up with that \

SPECIAL_ONE: {0, 0, 0, 1, 1, 2}

loop I over {0, 1, 2, 3, 4, 5}{
 loop J over {1, 2, 3, 4, 5}{
  output [count I in JdSPECIAL_ONE] named "[I] in [J] SPECIAL_ONE"
 }
}

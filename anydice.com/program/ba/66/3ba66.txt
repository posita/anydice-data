
function: ROLL:n dice A:n times for B:d dmg {
X: 0
if ROLL = 1 {X: 0}
if ROLL = 20 {X: B + B + DMG_BONUS}
if ROLL >= 18 {X: B + DMG_BONUS}
if A > 1 {
A:A-1
X: X + [[highest 1 of 3d20] dice A times for B dmg]
}

if {X} > 0 {X: X + SNEAK}
result: X
}
DMG_BONUS: 6
SNEAK: 3d6

output [[highest 1 of 3d20] dice 2 times for 1d6 dmg]

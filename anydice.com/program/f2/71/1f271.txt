function: evof ROLL:n plus BONUS:n
{
  TOTAL: ROLL + BONUS
  if (TOTAL >= AC+10) {
    result: 2
  }
  else {
    if (TOTAL >= AC) { result: 1 }
    else {result: 0}
  }
}

function: attack AC:n with BONUS:n for DAMAGE:n deadly D:n {
  ROLL: [evof 1d20 plus BONUS]
  result: (ROLL * DAMAGE) + ([highest of ROLL and 0] * D)
}

DMG: 1d6 + 1d8
AC: 16
ATTACK: 6
output [attack AC with ATTACK for DMG deadly 1d10]

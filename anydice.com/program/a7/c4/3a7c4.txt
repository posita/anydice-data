\
 A "Crit" doesn't add much only like 0.25
 This system for resolution is within 4% of the original, however bonuses scale quite a bit harder.
 A bonus of + 10 gives a difference of 8%
 A bonus of + 20 gives a difference of 12%
\

function : whtest D:s S:n N:n B:n
{
 if D > S+B{
  result : 0
 } else if D <= S/N+B {
  result : 2
 } else {
  result : 1
 }
}

N : 5
B : 20
S : 50
E : 50
D: [whtest 1d100 S N B]* 10 + [whtest 1d100 E N 0]
output D
output [count {10, 20, 21, 30, 31,32} in D]

output (1d100 <= S+B) - (1d100 <= E)

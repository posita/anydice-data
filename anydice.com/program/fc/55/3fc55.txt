function: damage D:n if R:n beats A:n {
  if (R >= A) { result: D }
  result: 0
}

AC: 18

RE: d20 + 8
RZ: d20 + 8
RD: d20 + 8

DE: 1d8 + 2d6 + 5
DZ: 1d8 + 2d6 + 5
DD: 1d8 + 1d6 + 5

output [damage (DE + 2d6) if RE beats AC] + [damage (DZ + 2d6) if RZ beats AC] + [damage DD if RD beats AC]
output [damage (DE + 3) if (RE + 3) beats AC] + [damage (DZ + 3) if (RZ + 3) beats AC] + [damage DD if RD beats AC]

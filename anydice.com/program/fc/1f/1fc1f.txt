\
Contains functions to simulate a full 10 object attack with the animate objects spell
Also includes calculations for the spell while crusader's mantle is active
\
PROFICIENCY: 4 \ extrapolated from subtracting the damage bonus from the to hit \
ATTACKMOD: 4
TINY: 1d4 + ATTACKMOD
TINYCM: 2d4 + ATTACKMOD \cm stands for crusader's mantle\
TINYCRIT: 2d4 + ATTACKMOD
TINYCMCRIT: 4d4 + ATTACKMOD

\looped against enemy AC from x-y\
ENEMYAC: d{10..20}

function: ao ROLL:n vs AC:n {
 if ROLL >= 20 { result: TINYCRIT } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: TINY }
 result: 0
}

function: aocm ROLL:n vs AC:n {
 if ROLL >= 20 { result: TINYCMCRIT } 
 if ROLL = 1 { result: 0 }
 if ROLL + PROFICIENCY + ATTACKMOD >= AC { result: TINYCM }
 result: 0
}

output 10d[ao 1d20 vs ENEMYAC] named "ao"

output 10d[aocm 1d20 vs ENEMYAC] named "aocm"

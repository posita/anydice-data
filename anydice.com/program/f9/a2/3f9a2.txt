function: to hit AR:n mod M dmg D:n ac AC keen K fell F{
if (AR = 20) | (K & (AR = 19)) {
 if !F {result: D * 2 + M - 2}
 else {result: D * 4 + M-2}
}
if AR + M >=  AC {result: D + M-2}
else {result: 0}
}

C: [to hit [highest 1 of 2d20] mod 5 dmg d8 ac 15 keen 0 fell 0]
output B + B
output C + C

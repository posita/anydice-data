 MAX: [maximum of DIE]/#(DIE) 
 result: [hpo helper DIE MAX]

function: hpo helper SEQ:s N:n { \convert the DIE we passed to a sequence. Now we'll use the same roll throughout the function\
 X: [count N in SEQ] \So now X evaluates to a specific number depending for each roll, instead of a distribution\
 result: {1..X+1}@[sort SEQ] 
}

DEFAULT:LVL+PROF+STR+ITEM+OTHER-PENALTY
FINESSE:LVL+PROF+DEX+ITEM+OTHER-PENALTY

WEAPON_A: 1d12+STR
WEAPON_B: 2d12+STR
WEAPON_C: 1d8+STR

FOELVL:2
FOEDEX:3
FOEARMOR:3
FOEBONUS:2

AC:10+FOELVL+FOEDEX+FOEARMOR+FOEBONUS

function: X damage D:d E:n {
DMG:D+E
if X<=0 {result: 0}
if X=1 {result: DMG}
if X>=2 {result:(DMG)*2}
}


function: N attack A:s plus B vs ac AC dealing D plus E damage {
if N>3 {N:3}
TOHIT:A+B-((N-1)*MAP)
if TOHIT>=AC+10 {X:2} else if TOHIT>=AC {X:1} else {X:0}
if A=20 {X:X+1} else if A=1 {X:X-1}
result:[X damage D E]
}

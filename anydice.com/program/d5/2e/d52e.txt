\Adjust the variables below (MOD, DIE, NUMDIE, CRIT) to change calculation & click "Calculate" below the textbox\
\-------------------------------------------------------------------\
MOD:5     \This is the damage modifier. I.E. Strength modifier, etc.\
DIE:6     \Die size. I.E. DIE:6 for d6                              \
NUMDIE:2  \Number of damage dice. I.E. NUMDIE:2 for Greatsword/Maul \
CRIT: 20  \Minimum roll for a crit. Default 20                      \                                
\-------------------------------------------------------------------\

\Do not touch the code below.\

}

function: getcrit A:n B:n { 
 if A >= B { 
  result:2 
 }

  result:1 
 } 
}

MUL:[getcrit 1d20 CRIT]

output (MUL * [attack DIE NUMDIE]) + MOD

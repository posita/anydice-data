To create an AnyDice function that checks the probability of any two dice combining to a total of 7 when rolling 3 six-sided dice, you can use the following code:

```
function: check_sevens A B C {
  result: (A+B=7) | (A+C=7) | (B+C=7)
}

output [check_sevens d6 d6 d6]
```

This function, named `check_sevens`, takes three parameters representing the three dice rolls (A, B, and C). The `result` line checks if any pair of dice sums to 7 by checking the conditions (A+B=7), (A+C=7), and (B+C=7) using the `|` operator, which represents the logical OR operation in AnyDice.

Finally, the `output` line calls the `check_sevens` function with three six-sided dice (d6) and outputs the distribution of the results. In this output, a 1 represents a successful event (i.e., at least one pair of dice sums to 7), and a 0 represents a failure (no pairs sum to 7).

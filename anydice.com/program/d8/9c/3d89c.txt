DICE: 3
LUCK: 1
VALUE: 3

function: explode N:n {
 if [count{1..VALUE}in N] >0 { result: 1 + [count{1..VALUE}in 1d10] }
 result: [count{1..VALUE}in N]
}

LUCK_DIE_RESULT: [explode 1d10]
loop N over {1..(LUCK-1)}{LUCK_DIE_RESULT: LUCK_DIE_RESULT + [explode 1d10]}

output [count {1..VALUE} in (DICE-LUCK)d10] + LUCK_DIE_RESULT named "[DICE]d10 Luck:[LUCK]"

N:WS+2

GWD:d{{1..2}, {3..N}:N/2+1}

AC: 20

function: ATK:n plus PLS:n for CNT:n DICE:d plus BNS {
 if ATK=20 { result: (2*CNT)dDICE + MOD + BNS }
 if ATK=1 { result: 0 }
 if ATK+PLS+PRF+MOD >= AC { result: CNTdDICE + MOD + BNS }
 result: 0
}

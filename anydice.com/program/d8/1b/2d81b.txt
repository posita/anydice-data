function: roll ATK plus MOD vs AC for DMG_DICE and DMG_FLAT {
  if ATK = 0 {result: 0}
  if ATK = 20 {result: DMG_DICE + DMG_DICE + DMG_FLAT}
  if ATK + MOD >= AC {result: DMG_DICE + DMG_FLAT}
  result: 0
}

AC: 15

CHARISMA_MOD: 4
PROFICIENCY_BONUS: 3

SCORCHING_RAY_DAMAGE: 2d6
HEX_DAMAGE: 1d6
ELEMENTAL_AFFINITY: CHARISMA_MOD

SCORCHING_RAY_WITH_HEX_AND_ELEMENTAL_AFFINITY: [roll [highest 1 of 2d20] plus (CHARISMA_MOD + PROFICIENCY_BONUS) vs AC for (
SCORCHING_RAY_DAMAGE)]

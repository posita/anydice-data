DICE: 3
LUCK: 1
TO_HIT: 3

function: explode N:n {
 if [count{1..TO_HIT}in N] >0 { result: 1 + [count{1..TO_HIT}in 1d10] }
 result: [count{1..TO_HIT}in N]
}

LUCK_DIE_RESULT: [explode 1d10]
loop N over {1..(LUCK-1)}{LUCK_DIE_RESULT: LUCK_DIE_RESULT + [explode 1d10]}

output [count {1..TO_HIT} in (DICE-LUCK)d10] + LUCK_DIE_RESULT named "[DICE]d10 Luck:[LUCK]"
output [count {1..TO_HIT} in 3d10]

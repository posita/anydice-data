ASTR: 4
ASKILL: 4    
DSTR: 2     
DSKILL: 2

function: modify attack SEQUENCE:s{
 R: {}
 loop P over {1..#SEQUENCE}{
    E: P@SEQUENCE
    if E = 0 { E: -1 }
    R: {R, E}
 }
 result: R
}

ATTACK: [count {1..ASKILL} in ASTRd12]
ATTACK: [modify attack ATTACK]
DEFENSE: [count {1..DSKILL} in DSTRd12]
DIFF: ATTACK - DEFENSE
output DIFF

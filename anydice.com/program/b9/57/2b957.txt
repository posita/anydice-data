\This program calculates successes when doing downtime things in XGE.\

PB: 3 \your PB\
\PIT FIGHTING PARAMETERS\
PF_MOD_ONE: 3+PB \Mod for 1st skill check - an attack roll\
PF_MOD_TWO: 3+PB \Mod for 2nd skill check - acrobatics\
PF_MOD_THREE: 2+1d8 \Mod for 3rd skill check - Con check with HD bonus \

\GAMBLING PARAMETERS\
GB_MOD_ONE: 4+PB \Mod for 1st skill check - Deception\
GB_MOD_TWO: 4+PB \Mod for 2nd skill check - Intimidation\
GB_MOD_THREE: 2+PB \Mod for 3rd skill check - Insight\


\Use this if the roll has advantage and guidance\
function: outcome adv guide MOD:n{
DC: 5+2d10
ROLL: 1@2d20+MOD+1d4
A: ROLL>=DC
result: A
}

\Use this if the roll does not have advantage and guidance\
function: outcome guide MOD:n {
DC: 5+2d10
ROLL: 1@1d20+MOD+1d4
A: ROLL>=DC
result: A
}

\Use this if the roll has advantage \
function: outcome adv MOD:n{
DC: 5+2d10
ROLL: 1@2d20+MOD
A: ROLL>=DC
result: A
}

\Use this if the roll does not have advantage \
function: outcome MOD:n {
DC: 5+2d10
ROLL: 1@1d20+MOD
A: ROLL>=DC
result: A
}

output [outcome PF_MOD_ONE]+[outcome PF_MOD_TWO]+[outcome PF_MOD_THREE] named "Pit Fighting Successes"
output [outcome GB_MOD_ONE]+[outcome GB_MOD_TWO]+[outcome GB_MOD_THREE] named "Gambling Successes"

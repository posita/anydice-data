
function: freeroll AUNO:n ADUE:n BUNO:n BDUE:n {
if AUNO=1 & BUNO=1 {AUNO: -30 BUNO: -30}
if AUNO=1 & BUNO!=1 {result: 0}
if ADUE=1 {ADUE: ADUE-30}
if BUNO=1 & AUNO!=1 {result:1}
if BDUE=1 {BDUE: BDUE-30}

ARES: 1@[sort{AUNO,ADUE}]
BRES: 1@[sort{BUNO,BDUE}]
if ARES+BO>=BRES+BI {result:1} 
result: 0
}

DIE: 12
DIF: 14
BO: 4
BI:8
output [freeroll 1d [explode dDIE] 1d [explode dDIE] 1d [explode dDIE] 1d [explode dDIE]]

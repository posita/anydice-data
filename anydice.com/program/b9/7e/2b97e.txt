output {1,1,1,2,3,4} named "Unskilled"
output 1d6 named "Skilled"
output 1d6+1 named "Skilled Bonus"
\how to use:\
\Go to the Roller view\
\If unskilled, set the number to 1 and the dropdown to unskilled\
\If skilled, set the number to however many points in the relevant skill and set the dropdown to skilled\
\If you have an enhancement that gives you a +1 bonus on rolls for a specific skill, use skilled bonus for it.\

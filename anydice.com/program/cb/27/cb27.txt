\A is 1d100, B is WS/BS, D weapon die, X difference between damage bonus and armor\
function: ow A:n B:n D:d X:n{
 if A>B {result: 0}
 if A=B {result: 1d[dam D]+4}
 if B>A {result: [help B-A D X]}
}

\A is difference between BS/WS and roll, D is weapon die, X is damage bonus\
function: help A:n D:d X:n{
 B:(A/20+1)
 result: Bd[dam D]+B*X
}

function: dam D:n{
 result: D
}

output [ow 1d100 75 1d10 1]
